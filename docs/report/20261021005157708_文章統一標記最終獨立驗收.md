# 文章統一標記：最終獨立驗收

狀態：本地實施及最終獨立驗收完成。最後一輪針對修復後程式的 64 項瀏覽器檢查全部通過；未部署正式服務。

## 實施與行為

已按[批准計劃](../plan/20261020232913915_文章統一標記與筆記改造計劃.md)委派使用者指定的「代碼執行」（assistant_id: 1）實施，主代理另以隔離瀏覽器、合成資料和 mock 做獨立覆核。

| 操作 | 結果 |
| --- | --- |
| 查詞、短語、句子 | 保存查閱記錄與解釋，不自動標記 |
| 手動標記、加入詞書 | 標記當前位置，用統一實線下劃線呈現 |
| 取消標記 | 保留詞書、釋義、關聯和筆記；重查、刷新不會自行重新標記 |
| 再次主動加入詞書 | 可重新標記當前位置，包括詞書已有同詞的情況 |
| 寫筆記 | 自動保存到對應文章與位置，不改標記狀態 |
| 移除詞書條目 | 保留文章標記及筆記 |
| 手機選短語 | 點首詞、點末詞，再加入詞書、標記或寫筆記 |

資料沿用既有 learningItem，新增 marked 布林值；articleId、contentVersion、anchor 維持文章及精確位置關聯，沒有另建標記表。舊 understanding 僅用於兼容遷移，新介面及 AI 整理不再以它判斷理解程度。詞條、來源關聯、主動標記及 outbox 在同一交易保存；遷移失敗可重試，明確 false 優先。

## 已發現及修正的問題

主實施報告的通過結論，須連同後續覆核修復一起閱讀，不能把早期版本視為最終交付版本。

- 遷移失敗被當作載入成功：修正失敗回報及可重試行為。
- 重複詞第二個位置已標記，但重開彈窗顯示第一個位置狀態：改為按位置與版本讀取。
- 舊詞彈窗回應覆蓋新選詞、帳戶切換後寫錯帳戶：固定請求上下文與彈窗 session。
- 舊文章版本的詞查詢仍合併至新版 legacy analysis：增加版本寫入檢查；獨立測試使用帶 sentence 的真實結構回應，避免被合併函式丟棄而產生假通過。
- 舊句卡點擊時重新擷取新版上下文：卡片建立時固定文章、版本、位置和帳戶；刷新、短語詳解、選區、加入詞書及重試均沿用原歸屬。首次解析的延遲回應也檢查正文版本與原卡片是否有效，相關回歸已通過。

## 發佈範圍與限制

這次修改與驗證在本地工作區完成，未 commit、push 或部署正式服務。未改動 ai-config.js，沒有用真實 AI／正式帳戶測試。

新前端要求後端宣告 learningItemMarked 能力。舊後端不支援時，閱讀資料同步暫停並提示更新；本地資料與待同步 outbox 保留。正式發佈需先更新後端、再上前端。本次以本地 selfhost／mock 驗證能力閘門，未驗證正式雲端或實體 iOS／Android 裝置。

本次版本保護覆蓋按需查詞、句子、短語與句卡操作。既有整段解析重試 `retrySingleParagraph` 不在本次標記改造範圍內，仍未帶 `expectContentVersion`；如在整段重試期間修改正文，尚有舊分析回寫新版的風險。此項已在版本修復報告記錄，未將其宣稱為已修復。
