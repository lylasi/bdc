# 擴充套件 0.6.0：精簡介面、文章助手與詞書關聯交付驗證

狀態：本地實作與交付包完成；主站檔案尚未部署。使用者已確認全部推薦，無待決產品選項。

## 完成行為

- 工具列下拉改為狀態、助手／文章／詞書快捷入口及懸浮球開關，移走常駐語境輸入表單與 AI 設定摘要。
- 查詞小卡保留字詞、音標、詞性、句中釋義與加入詞書；圖示提供 AI、編輯、更多、設定、關閉。詞書選單旁可直接打開所在詞書。
- 編輯／設定使用原生對話框，設定即存；獨立文章視窗等 AI 設定就緒後才啟用操作，避免初開競態；取消編輯會恢復詞卡與原網頁來源，不另發 AI 請求。Esc 先關對話框，快速重開不會套用上一個關閉事件的版面狀態。
- 頁內文章助手預設以懸浮球顯示，可即時切換顯示並保存選擇。沒有選字也能開；詞卡入口會引用當前單詞與原句。支援小窗／側欄、連續問答、串流、停止、原請求重試、新對話及本機草稿恢復。
- 對話按同步端點、帳戶、頁面 URL 與正文版本區分；切換帳戶清空畫面舊對話，遲到回應不跨帳戶顯示。歷史、引用及教材內容不隨 UI 語言轉換。
- 文章提取改用獨立視窗。右鍵「用 BDC AI 提取並導入文章詳解」會在獨立視窗提取、逐段分析及匯入，完成後在該視窗顯示 BDC 文章詳解。
- 文章視窗綁定發起操作的原分頁；開新視窗或切換作用中分頁不會換成另一頁正文。已擷取並保存後，即使關閉原分頁仍可開啟文章結果；不再讀取已失效來源的新內容。
- 文章工具列可直接查看對應詞書；無專屬詞書時經站內確認建立。詞書可返回文章及原文。
- 舊資料優先按 articleId、storageId／別名、明確詞書關聯及同一頁 sourceUrl 解析，不按標題猜測。未記錄來源的舊資料不會虛構連結。
- 詞書 JSON 匯出附帶可識別的文章 ID 與安全原文 URL；字詞維持舊版字串格式。匯入保留來源；覆蓋同名詞書保留詞書 ID。明確替換原文來源時清除過時文章 ID。

## 實作邊界

- 所有 AI 請求沿用 `modules/api.js`、既有協議適配與 `assistant.articleTutor` 共用提示詞；只新增擴充的 assistant 用途與可信 UI 接線。
- 新頁內入口沿用 closed shadow／extension iframe／sender／documentId／tabId／ticket 驗證；獨立視窗先建立空白目的分頁並綁定，再載入可信頁。
- 不新增雲端資料協議欄位；沿用已有 articleId、sourceUrl 等欄位。詞書來源變更亦保存到永久層。
- `ai-config.js` 私有設定未讀取或封裝；包內設定與 `ai-config.example.js` 位元組一致。共享 Key 仍走原有記憶體路徑。
- zh-CN／zh-HK 文案鍵一致；新增圖示有翻譯的 title／aria-label。
