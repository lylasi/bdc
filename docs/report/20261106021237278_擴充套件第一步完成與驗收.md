## 可以使用的能力

在沒有 BDC 網頁分頁的情況下，從擴充套件頁連接現有帳戶的 AI 設定，查詢單詞、短語、原句及附近語境。模型、思考等級、提示詞、語言規則及供應商協議共用主站邏輯。介面支援 zh-CN 及 zh-HK。

已驗證 managed 供應商、雲端個人 Key、已有帳戶供應商定義的本機 Key 明確匯入；共享 Key 只留記憶體。無原句時提供通用單詞釋義；有原句時按語境分析。真實選區能區分同段中兩個 charge，不會把充電誤取成收費原句。

修改輸入、語言、帳戶或端點會取消舊查詢並恢復按鈕。跨擴充頁切換端點不再錯送 token。快取區分實際上游及帳戶；備援模型、無效回應、下載失敗與 Key 綁定錯誤有正確來源及雙語狀態。內容腳本讀不到會話憑證。

## 安裝與連接

```bash
cd /Users/linus/CODE/bdc-extension-ai-proof-20261105
node scripts/package-extension.mjs
```

在 Chrome／Edge 擴充套件管理頁開啟開發人員模式，載入未封裝項目，選擇此工作樹的 `extension` 目錄。**打包是必要步驟**：生成的共享模組及配置不入版控，唯一源碼仍在主站 modules／locales／shared。

初次試用可從擴充套件選項打開查詞頁，填同步服務地址，連接帳戶後輸入詞及原句查詢。密碼登入的瀏覽器流程已以 mock 驗證；通行碼及一次性登入碼接口模式亦有單元測試。僅存於網站本機的 Key 不會自動跨 origin 複製，需明確匯入。真實 Worker 如採嚴格 ALLOWED_ORIGINS，管理員需加入實際 chrome-extension://<id>；本輪沒有修改生產配置。
