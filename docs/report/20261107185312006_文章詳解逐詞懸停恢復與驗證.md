# 文章詳解逐詞懸停恢復與驗證

文章詳解的整句預覽原本從整個 `.sentence-wrap` 尋找句尾按鈕，令鼠標滑過任一單詞時，都會高亮整個英文句及對應中文句。新增的回歸檢查在修正前成功重現：預期整句高亮數量為 0，實際為 2。

本次將整句預覽限定由句末三點按鈕的懸停或鍵盤焦點觸發。從按鈕或浮層返回正文單詞時，立即清除整句預覽；按鈕與浮層之間仍保留移入時間，浮層內的朗讀按鈕可正常操作。普通單詞懸停只呈現該詞的局部底色，點擊沿用既有單詞詳解，懸停樣式不發出 AI 請求。

實作修改位於 `features/article/sentence-actions.js` 與 `styles.css`；回歸覆蓋加入既有 `tests/article-sentence-hover.cjs`。兩種介面語言共用同一套行為及既有文案。
