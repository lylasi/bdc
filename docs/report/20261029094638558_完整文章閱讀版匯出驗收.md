## 完成內容

使用者要求的是可交給別人閱讀的完整成果。指定帳戶分享已移除，目前應用沒有相關 UI、API、資料表或新遷移；先前分享計劃及報告已標為撤回，保留歷史證據。

文章工具列及「本文學習記錄」面板的「匯出閱讀版」共用同一視窗，預設產生單一 HTML，包含原文、生詞及短語標記、句子解釋、個人與全篇筆記、生字簿關聯、已儲存的 AI 文件及本文對話。對話可取消勾選。Markdown 保留為另一格式，可選擇是否附上全文與對話；完整 JSON 備份使用「更多工具」的獨立入口，明確說明涵蓋目前帳戶的本機資料。

原文標記連到對應學習記錄，記錄可返回原文。重複及重疊位置分別保留；版本、起訖、quote 或位置確定狀態不符合時，將記錄列在「位置待確認」，不猜測或丟棄。顯示保存的首次／最後查閱及文章最後開啟時間，不推斷閱讀完成度。

HTML 可附加本機音訊，最多 5 個檔案、原始總大小 25 MiB。音訊以 data URL 內嵌，可獨立離線播放。目前應用沒有個人錄音的持久化資料；本次提供選取已有錄音檔案的能力。音訊只保留在當次匯出視窗，關閉後清除。

匯出先保存面板及短語選擇器的筆記草稿。檔案讀取或產生失敗會保留格式、範圍和所選音訊供重試；匯出中停用重複提交，保留取消操作。切換文章、帳戶或語言會取消舊工作，已取消的 FileReader 回應不能觸發下載。手機版進度及錯誤提示放在按鈕上方，不隨內容區捲出畫面。

HTML 使用單篇、單帳戶的持久資料快照，IndexedDB 及 localStorage 後備都限制相同範圍。暫時的 IndexedDB 讀取失敗不再令後續讀取永久轉向空白後備資料；損壞或讀取失敗明確回報，不能成功匯出成空內容。檔案標示本機範圍、待同步、衝突及位置待確認資訊。

產物不載入遠端圖片、字型、樣式或腳本；原始 HTML 及 Markdown 內容安全跳脫，憑證形式的來源連結不嵌入。無需開發伺服器，也不帶入帳戶 token、AI 供應商設定或 TTS URL。兩份 locale 新增相同的 62 個鍵，教材、筆記與歷史訊息原文不轉換。
