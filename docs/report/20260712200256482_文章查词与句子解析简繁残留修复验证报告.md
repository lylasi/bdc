# 文章查词与句子解析简繁残留修复验证报告

## 问题

用户选择大陆简体中文后，文章模块的动态界面仍出现以下香港繁体文字：

- `載入中...`
- `載入詳解中...`
- `加入生詞本`
- `加入生詞本（選中）`
- `詳解中...`
- `發音`
- `片語解析`
- `自訂片語...`

## 原因

这些文字由文章查词、句子解析和选词加入词书流程动态生成，原代码直接写入繁体字符串，没有经过 `t()` 翻译入口，因此切换界面语言时无法变化。

## 修改

- 在 `locales/zh-CN.js` 与 `locales/zh-HK.js` 补充文章查词、加载状态、句子解析、短语分析和加入词书相关翻译键。
- 将 `features/article/article.js` 中相关动态 `innerHTML`、`textContent`、提示框和按钮文字改为调用 `t()`。
- 将默认词书辅助逻辑接入 i18n：
  - 大陆简体显示“单词本”。
  - 香港繁体显示“生字簿”。
  - 继续兼容旧数据中的 `生詞本` 与 `单词本` 名称，不破坏已有词书内容。
- 将加入成功、重复、空内容等提示统一改为语言字典生成。

## Playwright 实测


```text

加入单词本
分析短语

```

```text

```

```text

详解

```

```text
發音
加入生字簿
解析片語
自訂片語...
```

句子解析即时状态：

```text
句子解析
正在載入詳解...
```

## 结论

用户反馈的文章单词查询“載入中”及句子解析“生詞本”等简繁混用问题已修复。相关交互链中的加载、查词、发音、短语分析、句子解析和加入词书按钮现在都会跟随当前界面语言。
