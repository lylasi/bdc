## 二、高嚴重度問題

### H1. 站內確認彈窗存在存儲型 XSS（`modules/ui.js`）

**位置**：`modules/ui.js` → `showOptionsModal()` / `createRadioOption()` / `createCheckboxOption()` / `createSelectOption()` / `createNumberOption()`

彈窗的 `title`、`description`、選項 `label`/`description`/`choices[].label` 全部以樣板字串串進 `innerHTML`，未做任何轉義。

**實證**：把詞書命名為 `<img src=x onerror="window.__xss=(window.__xss||0)+1">`，點「删除」後：

```
window.__xss = 1
彈窗 HTML：<p class="om-desc">確定要永久刪除單詞本“書<img src=x onerror="...">”嗎？…</p>
```

`ui.confirmAction({ message })` 與 `ui.showOptionsModal({...})` 直接呼叫亦同樣觸發（實測 xss 計數 1 與 6）。

**受影響呼叫端（皆帶入使用者可控字串）**：

- `features/vocabulary/vocabulary.js`：`defaultConfirmOverwrite(bookName)`、`?wordlistUrl=` 匯入確認、刪除確認
- `features/qa/*`：刪除問答集確認
- 任何把書名／檔名／URL／AI 產出當作 `message` 的呼叫點

**建議**：`showOptionsModal` 改用 `textContent` 逐節點組裝，或引入統一 `escapeHtml()`（`features/qa/qa-creator.js` 已有可複用的實作）。

### H4. `state.quizInProgress` 永遠無法清除，「離開測驗」確認會無限重複

**位置**：`main.js` 第 52–57 行

```js
if (state.quizInProgress && btn.id !== 'quiz-btn') {
    if (!confirm(t('quiz.leaveConfirmation'))) { return; }
    // 需要一个 stopQuiz 的引用，暂时从 quiz 模块导出
    // import { stopQuiz } from './features/quiz/quiz.js';
    // stopQuiz();
}
```

`stopQuiz()` 被註解掉（`features/quiz/quiz.js` 只匯出 `initQuiz` / `populateQuizBookSelector`），因此使用者按「確定」離開後 `quizInProgress` 仍為 `true`。

**實證**（只註冊單一 dialog handler、自動 accept）：

```
開始後 state: {"quizInProgress":true}
第 1 次點「學習模式」→ 對話框: ["测验正在进行中，确定要离开吗？"]  state: {"quizInProgress":true}
第 2 次點「單詞本」  → 對話框累計 2 次                          state: {"quizInProgress":true}
第 3 次點「聽寫模式」→ 對話框累計 3 次
回到測驗頁：settings hidden=true、main hidden=false、題目仍在、state 仍為 true
總對話框次數: 3
```

也就是說：**選擇離開後，之後每一次切換模組都會再彈一次確認，永遠不會停止**，除非回到測驗頁按「結束测验」。這是使用者每天都會碰到的死循環。

**建議**：把 `stopQuiz` 匯出並在 `main.js` 呼叫；同時確認「離開」語意是結束測驗還是保留進度。

## 五、建議修復優先順序

1. **H3**（`ai-config.js` 缺失即全站停擺）與 **M9**（`qa-sets` 型別異常中斷啟動）——合併為「啟動路徑韌性」一次性處理，是「使用者看到白畫面卻毫無線索」的根因。

5. **H6**（問答集丟行）—— 影響資料正確性，需補 `warnings` 通道。
6. **M1**（提示遮擋）、**M2**（靜默失敗）、**M4**（原生對話框）—— 統一「提示與錯誤處理」規範。

8. **M5 / M6 / M11 / M12 及低嚴重度項**—— 依排期處理。
