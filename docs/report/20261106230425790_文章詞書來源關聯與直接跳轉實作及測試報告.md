## 三、關聯解析 API

### 純函式（`shared/article-book-link.mjs`，不碰 DOM／儲存）

- `articleIdentityIds(article)`：文章公開 ID、`storageId`、`referenceIds` 別名集合。
- `matchVocabularyBookForArticle(article, books, options)`
  - 優先序：`linkedBookId` → 詞書 ID 等於文章身份 → 詞書 `articleId` 指向文章身份 → 同一頁 `sourceUrl`。
  - 同名不算關聯；同分候選 deterministic，並回傳 `ambiguous`。
- `matchArticleForVocabularyBook(book, { articles, metas })`
  - 支援文章 `storageId` 別名、文章 meta 的 `linkedBookId` 反向指向、同頁網址補救。
- `safeHttpSourceUrl(...values)`：只回傳安全 http(s)。

### 主站包裝（`modules/article-book-link.js`）

- `resolveVocabularyBookForArticle(articleIdOrRecord, { books? })`
  - 回傳 `{ book, bookId, match, ambiguous, candidates, sourceUrl, article, articleMeta }`。
- `resolveArticleForVocabularyBook(book)`
  - 回傳 `{ articleId, article, articleMeta, canOpenArticle, sourceUrl, match, ambiguous, deleted }`。
  - `articleId` 指向 `storageId` 時會換成公開 ID；刪除中的文章不顯示回文章。

### 路由（`modules/vocabulary-route.js`）

- `readVocabularyRoute(hash)`、`isValidVocabularyBookId(id)`、`vocabBookHash(id)`、`writeVocabularyRoute(id, { replace })`。

### 詞書模組

- `selectVocabularyBook(bookId, { updateRoute })`：主站路由、列表點選共用；使用者主動選書時以 replaceState 同步 `#v/<id>`。
