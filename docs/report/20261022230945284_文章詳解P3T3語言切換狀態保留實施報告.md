## 一、摘要

切換介面語言（zh-CN ↔ zh-HK）時，原本的做法是直接把整個 DOM 移除重建：

- 助手：草稿、游標、模式、捲動位置與進行中的會話全部消失，且 `hashchange`／nav click／`resize` listener 每切一次就多一份。
- 閱讀面板：面板被關掉、篩選與捲動位置歸零；歷史記錄彈窗重建後 scroll 與搜尋焦點歸零。
- 短語面板：sheet 直接被移除，未保存的筆記草稿雖仍在 debounce timer 裡，但畫面與選取範圍消失。
- 單詞 tooltip：可見時雖會重畫，但焦點可能留在 `body`。

本次以「先 capture、重建、再 restore」的順序改寫四處 locale listener，並以遞增 `localeToken` 防止非同步 restore 覆蓋較新的語言。新增 2 個翻譯鍵（兩語齊備、無插值），新增 Playwright 驗收腳本 `tests/locale-panel-state.cjs`（42 項檢查，全綠）。

## 三、capture／restore 流程

### 3.1 助手（`features/assistant/assistant.js`）

**capture（同步，在移除 DOM 前）**

```
{
  wasOpen,                       // #assistant-panel 是否未帶 assistant-hidden
  mode,                          // 由 panel class 推導 floating／dock／modal；無 panel 時用 getSavedPanelMode()
  inputValue,                    // #assistant-input 全文
  selectionStart, selectionEnd,  // 游標／選取範圍
  inputFocused,                  // document.activeElement === input
  scrollTop,                     // #assistant-messages 的 scrollTop
  convId,                        // 最後一則訊息節點上的 data-conversation-id
  articleKey                     // 由 readIndex() 反查會話 meta 的 articleKey（取不到時退回 data-article-id）
}
```

**listener 順序**

1. `token = ++localeToken`
2. `snapshot = captureAssistantUiState()`（另保留舊 `#assistant-input` 節點參照，供串流中止後補讀草稿）
3. 若 `activeAsk` 存在：`activeAsk.controller.abort('locale-change')`，沿用 P1-T5 既有的 `cancelled` 分支與半段保存，不動 checkpoint
4. `teardownVisibilityLogic()`：`clearTimeout`、移除 `hashchange`、`disconnect()` MutationObserver、移除 nav 按鈕 click、清掉 wirePanel 掛在 `window` 的 `resize` listener
5. 移除 history panel／assistant panel／fab → `mountUi()` → `setupVisibilityLogic()`
6. `restoreAssistantUiState(snapshot, { token, waitForAsk, refreshDraftFrom })`

**restore**

1. `token !== localeToken` 直接放棄（舊 restore 不得覆蓋新語言）
2. 串流中：`await waitForAssistantIdle()`（最多 6 秒）等 P1-T5 把 `cancelled` 半段存完
3. 補讀舊 textarea 的草稿（中止流程可能把原問題寫回舊節點）
4. 還原 mode（`setPanelMode`；dock 另套 `setDockWidth`）、以 `convId` 反查並釘回目前會話
5. `wasOpen` 時顯示面板、`restoreConversation()`（`activeAsk` 仍存在時跳過，避免清掉進行中的請求 UI）、重算 context chip 與會話標籤
6. 還原草稿、`autoGrowInput`、`#assistant-messages` scrollTop、游標（聚焦後再套一次 `setSelectionRange`，避免焦點把 caret 推到結尾）
7. 只有草稿非空時才 `addHint(panel, t('assistant.localeKeptDraft'))`；面板每次切換只會有一則提示

### 3.2 閱讀面板（`features/article/reading-panel.js`）

**capture**：`{ wasOpen, articleId, scrollTop, focusedItemId, focusKind, filter, savedOnly }`

- `focusedItemId` 由 `document.activeElement.closest('.reading-item')` 取得；`focusKind` 區分筆記 textarea 與其他卡片內元素。
- `filter`／`savedOnly` 本來就是 module 變數，仍一併帶入快照以便還原時驗證。

**listener**：`task` 化為 async

1. capture → `++localeToken` → `panel.remove()`（`noteDrafts` 不清、`document.body.reading-panel-open` 保持，避免版面跳動）→ `ensurePanel()`
2. 面板未開：只 `loadArticle(articleId)`，維持原本「重畫標記／計數」行為
3. 面板開著：先寫回 `filter = snapshot.filter; savedOnly = snapshot.savedOnly;`，再 `await openPanel(articleId, { restore: true })`
4. `token` 仍最新且面板開著才 `restorePanelView(snapshot)`：`#reading-panel-list` scrollTop（失敗退回頂部），焦點以 `[data-note-id]`／`.reading-item[data-item-id]` 找回；找不到就退回關閉鈕，焦點不留在 body
5. 顯示一次 `t('article.localeKeptPanel')` 提示

**歷史彈窗**：`refreshHistoryModal()` 先讀 `.ar-history-list` 的 `scrollTop` 與 `#ar-history-search` 的焦點／選取範圍，重建後還原；`historyUi`（sort/source/query/open）本來就是 module 變數，未重建。

### 3.3 短語面板（`features/article/phrase-picker.js`）

**capture**：`{ wasOpen, articleId, sentence, context, sentenceStart, startIndex, endIndex, focusedTokenIndex, noteOpen, noteFocused }`

**listener**

1. `state` 不存在（sheet 未開）→ 只重建 DOM，沿用舊行為
2. `await flushPhrasePickerNote()`；`token` 已非最新就直接交棒給後續切換
3. flush 失敗：**不 remove** 舊 sheet，只 `status(t('article.saveFailedRetry'), 'error')`，草稿留在原 textarea
4. flush 成功：remove + `ensureSheet()` + `openPhrasePicker({ articleId, sentence, context, sentenceStart })`
5. 還原 `startIndex`／`endIndex`（同一句推導出的 token 索引穩定）→ `markTokens()`／`updatePreview()`／hint 文案
6. `noteOpen` 時程式化點擊 `#phrase-picker-note` 重新載回已保存的筆記
7. 60ms 後還原焦點（避開 `openPhrasePicker` 內 30ms 的起詞聚焦）：優先原本聚焦的 token，其次起詞；筆記區塊開著且原本在輸入時聚焦筆記 textarea

### 3.4 單詞 tooltip 與歷史彈窗（`features/article/article.js`）

- 可見 tooltip：沿用既有 `wordTooltipLastPayload` + `rerenderVisibleWordTooltip()`；新增焦點校正（原本在 tooltip 內、或掉到 `body`／失效節點時 → `focusWordTooltipTitle()`）。觸發詞已移除時仍走 `dismissWordTooltip({ restoreFocus: false, source: 'locale-trigger-removed' })`。
- `refreshHistoryModal()`：保存／還原清單 scrollTop 與搜尋框焦點與選取範圍。

## 六、殘留風險與已知限制

1. **助手串流 restore 的時間窗**：切語言後最多等 6 秒（`ASSISTANT_LOCALE_IDLE_TIMEOUT`）讓 cancelled 半段落盤。若供應商卡住超過此值，面板會先還原 draft／open，半段訊息要等下次重開會話才出現；訊息本身仍會以 `cancelled` 保存，不會變成完整回答。
2. **助手提示氣泡**：每次切語言且草稿非空會新增一則 `assistant.localeKeptDraft` 提示；舊提示隨面板重建消失，因此不會累積，但連續切換多次會連續看到提示。
3. **閱讀面板 scroll 還原**：依賴 `openPanel` 內最後一次 `renderPanel` 的結果。若切換後立刻發生遠端同步／scope 重載的整份重繪，仍有機會把 scroll 帶回頂部（任務允許的降級）；草稿、open、filter、焦點不受影響。
4. **savedOnly + marked 可能為空清單**：此時 scroll 退化為頂部（空清單無可捲動內容），符合「scroll 可降級、狀態不可丢」。
5. **短語面板重開失敗**：`openPhrasePicker()` 在沒有 token（例如句子被清空）時回 `false`，sheet 會維持關閉；筆記已在 flush 階段保存，資料不丢。
6. **焦點策略改變**：tooltip 在 locale 切換時若焦點原在 `body`（滑鼠點開），會主動移到 `#word-tooltip-title`。這是為了滿足「焦點不跑到 body」的鍵盤可及性要求，滑鼠使用者會看到焦點環。
7. **Escape 監聽**：閱讀面板與短語面板的 document keydown 改為單次綁定（面板重建不再重複綁），行為不變。
8. **未變更項**：`analysis_run`／checkpoint 邏輯、`readIndex`／會話索引、同步協議與 Worker／selfhost 均未改動；沒有新增持久化欄位（助手與面板狀態仍只存在記憶體）。
