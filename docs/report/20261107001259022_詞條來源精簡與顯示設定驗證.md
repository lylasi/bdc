# 詞條來源精簡與顯示設定驗證

日期：2026-11-07（Asia/Shanghai）

## 完成行為

詞書清單每個單字的「來源」改為細小的行內摺疊入口。收起時沒有整行外框或面板底色；空間足夠時緊接音標及釋義，窄螢幕可自動換行。入口高度由原本至少 44px 縮為 28px，測試單一來源入口寬度約 75px。展開後以左側細線排列原網頁、原句、當時釋義、附近語境及日期。

在「全局設定 → 介面」新增開關：簡體為「显示单词来源」，香港繁體為「顯示單字來源」。預設開啟；關閉即時隱藏詞書清單內的單字來源入口，選擇自動儲存於本機，重新載入後仍生效。來源資料繼續保留，重新開啟可再次查看。

寫入失敗時，開關回復至實際儲存的值，並顯示相應語言的自動儲存失敗提示；不會在沒有成功儲存時顯示成功狀態。

## 實作位置

| 檔案 | 修改 |
| --- | --- |
| `styles.css` | 覆寫來源專用摺疊樣式，縮小入口與展開內容間距；保留原生鍵盤操作及焦點提示。 |
| `features/vocabulary/vocabulary.js` | 讀取來源顯示偏好，傳遞至增量渲染；隱藏時不建立來源 DOM。 |
| `features/sync/sync.js` | 介面分類加入開關、即時儲存、設定變更通知及儲存失敗回復。 |
| `modules/settings.js` | 新增 `vocabulary.showSources: true` 預設值；讀取及寫入均合併同組欄位。 |
| `locales/zh-CN.js`、`locales/zh-HK.js` | 同步新增 `settings.showWordSources`、`settings.wordSourcesHint`。 |

此偏好存於 `pen_global_settings.vocabulary.showSources`，使用既有 `bdc:settings-change` 及 storage 監聽更新清單。已檢視同步邊界：屬本機顯示偏好，沒有加入學習資料快照或 AI profile。
