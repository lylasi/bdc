## 三、設計決策

### 3.1 尺寸與版面

| 情境 | 寬度 | 高度 | 內容 |
| --- | --- | --- | --- |
| 選詞小窗（compact） | 340（窄卡 320） | 內容自適應，實測 232 | 工具列一行 → AI 設定一行 → 結果 → 收藏 |
| 完整面板（expanded） | 420（窄 320） | 視窗高 −24，內部捲動 | 工具列 + 查詢／結果／收藏／文章 |
| 帳戶設定頁（`lookup.html` 直開或 `default_popup`） | 400（≥320 不溢出） | 表單自然高 | 表頭 + AI 設定 + 帳戶 + 查詞 + 結果 + 收藏 + 文章 |

- 版面不再用卡片：`.ext-section` 以 `border-top: 1px solid var(--ext-line)` 分區，內嵌模式的首段（結果區）取消上緣線，避免與工具列的髮絲線重疊。
- 內嵌卡片為白底、10px 圓角、單一柔和陰影；小窗工具列 `position: sticky; top: 0`，以負邊距滿版延伸背景，捲動時仍只有一條分隔線。

### 3.2 統一的樣式語言

- 令牌（`:root`）：`--ext-ink`／`--ext-ink-soft`／`--ext-ink-muted`、`--ext-line`／`--ext-line-strong`、`--ext-surface[-2/-3]`、`--ext-accent`（`#0f766e`，與 BDC 主站主色一致）、`--ext-danger`／`--ext-warn`／`--ext-info` 與各自淺底、`--ext-radius-sm/`、`--ext-ring`。
- 字級：17（結果詞）／14（句中釋義、確認標題）／13（正文、按鈕）／12（標籤、說明、次要按鈕）／11（模型資訊、chip）。
- 間距：4／6／8／10／12 五級；區塊上下 12（小窗 8）。
- 控制項：輸入與 Select 30px、次要按鈕 26px、圓角 6px；Select 用內嵌 SVG 箭頭（data URI，不需外部檔案）；checkbox 用 `accent-color`。
- 焦點：所有按鈕、輸入、Select、`summary` 共用 `:focus-visible` 環（`0 0 0 3px rgba(15,118,110,.28)`），不影響滑鼠操作外觀。
- 狀態：`.ext-notice`（中性）／`.ext-notice-info`（藍）／`.ext-notice-error`（紅）以 `inset box-shadow` 描邊，避免出現／消失時位移。

### 3.3 主次與收合

- **主要**：查詞結果（詞／音標／詞性／句中釋義）、收藏（目標詞書 + 主按鈕）。
- **次要（原生 details 收合）**：
  - `#ext-account-details` / `#ext-account-summary`：登入表單、登入方式、按鈕列、`#ext-readiness-box`；預設 `open`（未登入保持展開），由 `lookup.js` 依登入狀態切換。
  - `#ext-query-details`：所在原句 + 附近語境（預設展開，可收起；小窗另以 class 收起整塊）。
  - `#ext-result-details`：例句（無例句時以 `:not(:has(li))` 自動隱藏）。
  - `#ext-capture-pending` / `#ext-workspace-pending`：沿用原生 details，summary 統一為「標題 + 右側箭頭」。
- **不可藏**：`#ext-inline-status`（登入提示）、`#ext-inline-action-notice`、`#ext-lookup-notice`、`#ext-capture-notice`、`#ext-workspace-notice`、`#ext-account-notice`、`#ext-missing-key-banner`、`#ext-capture-pending` 摘要列（小窗也保留一行，可就地展開重試）。
- 小窗（`.ext-compact`）只隱藏：區塊標題、`#ext-result-role`、`#ext-result-meta`、來源網址與 hint、`#ext-capture-refresh`、建書按鈕列／表單、文章區、強制刷新勾選、原句／語境輸入（按「編輯選詞」時改為顯示詞與查詞按鈕）。

### 3.4 AI 控制區（與並行改動的接合）

`extension/ai-controls.js`（並行實作）在 `#ext-inline-toolbar` 或 `.ext-header` 之後插入 `<details id="ext-ai-controls">`。本輪只提供 CSS，並依其實際 DOM 校準：

- `> summary`：`.ext-ai-summary-label`（不換行）+ `.ext-ai-summary-value`（`flex:1; min-width:0;` 單行省略）+ 右側箭頭；小窗高度 24px，收合成一行。
- `.ext-ai-grid`：`>=400px` 三欄（用途／模型／思考），`<400px` 兩欄且第三項整列；`.ext-field` 都 `min-width: 0`、Select `width: 100%`，320px 無橫向溢出（實測）。
- `.ext-ai-hint`、`.ext-ai-actions`、`#ext-ai-notice`（沿用 `.ext-notice`／`ext-notice-info`／`ext-notice-error` 配色）。
- 內嵌模式（小窗／完整面板）在 AI 區下方補一條髮絲線，接續結果區。
