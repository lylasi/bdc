# 詞條來源圖示與彈窗統一驗證

日期：2026-11-07（Asia/Shanghai）

詞書清單的「來源（數量）」摺疊入口已改成右側操作列的文件圖示，與朗讀、拆音練習共用 38px 圓形按鈕樣式、顏色與懸停效果。滑鼠提示及無障礙標籤包含單字與來源數量；沒有來源的詞條不顯示此按鈕。

點擊圖示後，以既有站內彈窗顯示所有來源，包括原網頁、原句、當時釋義、附近語境及日期。沒有網址的來源仍可顯示標題。彈窗支援關閉按鈕、背景點擊、Esc、Tab 焦點循環與關閉後返回圖示；長語境在彈窗內捲動，長單字標題在窄螢幕自動換行。內容透過文字節點建立，網址沿用既有安全檢查。

簡體及香港繁體文案、提示、無障礙標籤和設定說明同步更新。「顯示單字來源」開關繼續即時隱藏或顯示圖示。此次沒有新增持久化欄位；來源內容在開關與語言切換後保持原樣。

| 修改位置 | 內容 |
| --- | --- |
| `features/vocabulary/vocabulary.js` | 來源圖示及按需建立的來源彈窗。 |

| `locales/zh-CN.js`、`locales/zh-HK.js` | 彈窗標題、圖示提示及設定說明。 |
| `tests/extension-capture.cjs` | 既有收藏回歸改為檢查來源彈窗。 |
| `index.html` | 重新產生靜態資源版本：`2debbfc5f6be`。 |
