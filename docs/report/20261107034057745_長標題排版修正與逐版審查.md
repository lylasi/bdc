# 長標題排版修正與逐版審查

日期：2026-11-07（Asia/Shanghai）

詞書使用整段文章作名稱時，原有標題與五個操作按鈕擠在同一行，造成標題變成大量短行。現已將標題獨立成行、最多顯示兩行；省略時顯示資訊圖示，點擊可在彈窗查看完整原名。儲存的名稱及教材原文保持原樣。

操作列置於標題下方。手機或詞條面板內容寬度不超過 480px 時，五個操作統一收進更多選單，避免平板雙欄中只剩一個按鈕另起一行；選單位置依實際標題高度計算。詞書編輯及詞條來源彈窗改用短標題，完整名稱／詞條放入輸入欄或可捲動內容區。

QA 與文章庫卡片的標題同樣最多兩行，提供完整名稱提示；QA 預覽在可捲動內容中保留全名。更多選單避開頂欄與底部導覽，空間不足時可捲動；入口仍有可見部分便可開啟，完全離開操作區或頁面繼續捲動時才收起。從選單開啟彈窗，關閉後焦點返回可見入口。

父代理驗證：兩種語言下的 1024px、390px、320px 功能巡檢 **42/42 通過**，包含兩行限制、全文保留、彈窗、關閉焦點、更多選單、長詞來源與短名稱隱藏圖示；無頁面例外。既有 `tests/article-book-link.cjs`、`tests/vocabulary-source-transfer.cjs` 均通過。雙語字典鍵集合與插值一致；全庫掃描仍有既有 `.claude/worktrees` 的 `phonetics.`、`a.b` 假警示。JavaScript 語法、靜態資源版本及差異檢查通過。

DSH 標題量測為 **88/88**（簡繁 × 11 種寬度，320–1440px × 4 種標題），QA／文章庫／匯入等代表畫面為 **24/24**，另有完整名稱與閱讀記錄／新聞標題 **24/24**，均無版面缺陷。這些完整矩陣在 V4 穩定版本量測；V5 僅有單行入口守衛差異，另以 88 個定點案例覆驗。功能案例有重疊，沒有合併成單一總數。

瀏覽器使用獨立工作階段，長標題採合成資料，文章庫另包含既有教材巡檢。本次修改在本機工作區完成。極矮的 320×260 視口依賴選單內捲動；自動化工具在程式捲動尚未結束時點擊，後續捲動會收起選單，正常先捲後點的順序已通過。
