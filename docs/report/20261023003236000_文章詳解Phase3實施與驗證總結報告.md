## 二、關鍵行為

### 2.1 分析 checkpoint

- 初始保存即寫 `analysis_run.status = running`；每段成功或失敗後排程，degrade 為 1.2 秒 debounce，佇列序列化，同一時間最多一個寫入。
- checkpoint 使用 `saveAnalysis(..., { expectContentVersion, ctx, silent: true })`：更新記憶體與持久層，但不重繪歷史列。
- checkpoint 保留 `total` 長度陣列，未完成段為 `null`；顯示為「待分析」，統計不把 null 算失敗。
- 取消先 flush，再寫 `cancelled`；最終保存成功後以 `finalSaved` 阻止後續取消覆蓋。
- 重載時只有 `analysis_run.contentVersion` 與目前正文一致，才顯示「已保存 N/M」與續作；續作只跑 pending／failed 段，跳過已完成、null、純圖片與中文原文。
- `settings.reading.analysisCheckpoint === false` 時完全回到舊行為：不建 `analysis_run`、不排 checkpoint、無續作 banner。

### 2.2 快取治理

- `getItem` 發現 TTL 過期時同時刪 IDB 與 localStorage，不再只留 IDB 垃圾。
- `pruneCache` 只處理 `bdc:cache:v1:` 前綴；支援 `maxEntries`、`maxBytes`、`maxAgeMs`，回傳 `{ ok, removed, kept, fallback }`。
- `main.js` 初始化後以 `requestIdleCallback`（fallback `setTimeout`）執行，`bdc:cache:lastPrune` 保證 24 小時內不重複掃描。
- `clearRebuildable()` 改與 prune 共用掃描；沒有 `openCursor` 的環境（含測試替身）退回 `getAll`，避免靜默不刪。
- 頁內查詞 key 含內容版本、locale、模型、句子與詞；locale 切換清空；空 meaning／空譯文不寫快取、不記成已查閱。

### 2.3 locale 切換

- 助手：capture 草稿、游標、模式、會話、scroll、open；串流中先 abort（沿用 cancelled／半段保存），再 teardown 舊 observer／listener、重建、restore；`localeToken` 阻止舊 restore 覆蓋新語言。
- 閱讀面板：保留 filter／savedOnly／scroll／焦點，`noteDrafts` 不清；短語面板先 flush 筆記，失敗不關閉並提示重試。
- tooltip 以最後 payload 重畫；歷史清單保留 scroll 與搜尋焦點。

### 2.4 分詞

- `segmentWords` 優先 `Intl.Segmenter`，fallback Unicode regex；回傳 `{ word, start, end }`，只包 DOM、不改文字。
- 支援 `café`、`naïve`、`don't`、`O’Neill`、`co-operate`、`COVID-19`、`B2B`、`3D`；不把小數、網址尾點切成詞。
- 跳過 `a, code, pre, kbd, samp, script, style, textarea` 等語義節點；點連結不開查詞、不 `preventDefault`。
- 錨點／標記／朗讀仍以原句與原文 offset 定位。

### 2.5 效能探針

- 只在 `?perf=1` 或 `localStorage['bdc:perf'] === '1'` 啟用；關閉時不安裝 observer、不建立 `window.__bdcPerf`、不新增 DOM／listener。
- 量測欄位：字數／段數、DOM 節點、`.interactive-word`、long task、analyze 完成時間、點詞 p50／p95、`buildReadingChunks`、助手 context 字元與請求數。
- 報告只寫數量與耗時，不寫文章內容；JSON 不記錄實際點過的詞，只記 `clickedWordCount`。不上傳。

### 3.1 本輪額外修正

1. **快取清理在無 `openCursor` 環境靜默不刪**：`clearRebuildable()` 原本只走 cursor；測試替身與極舊環境不會刪 IDB。改為共用 `scanIdbCacheRows()`，退回 `getAll`。
2. **續作進度把失敗段算成「已保存」**：banner／歷史列改以 `completed - failed` 顯示成功保存數，避免 10/10 卻仍有失敗段。
3. **舊版查詞載入殼殘留**：文章改版後，延遲回應雖不寫入，但「載入中」殼仍顯示舊詞。新增 `staleSessionContext()`，在 session 仍屬於該次查詞但正文／文章／帳戶已失效時收起 tooltip；`dismissWordTooltip()` 同時清空內容。修復 `article-version-ownership.cjs` 的「改版後舊回應不重新顯示彈窗」。

## 五、剩餘風險與未完成事項

1. **checkpoint 寫入放大**：每 1.2 秒寫整份分析 JSON，`silent` 只減少 UI 事件，不減少 IDB／outbox 工作；10k／50k 的 checkpoint 成本尚未單獨量測。
2. **續作期間不逐段 checkpoint**：`resumeAnalysis()` 只在最後保存；續作途中重新載入會回到原本的 `analysis_run`，續作期間新完成的段不落盤（已完成段不會被刪）。
3. **關頁保存是 best effort**：`visibilitychange`／`pagehide` 不能保證瀏覽器終止前最後一刻一定寫入。
4. **partial 歷史語義**：最終 partial 仍會在歷史列顯示「已保存 N/M」；N 已排除 failed，但 skipped（中文原文／圖片）仍算完成，是否符合產品語義需確認。
5. **locale restore 邊界**：助手串流 restore 最多等 6 秒 settle；面板 scroll 依賴最後一次 render，快速重繪可能退回頂部（草稿／open／filter／焦點仍保留）。
6. **HTML 字串預先包字路徑**：`replaceOutsideTags` 仍使用舊 ASCII regex；表格／舊分析 HTML 路徑的連字號與重音詞可能先被切成舊片段，不影響本次 DOM 路徑驗收。
7. **設定未同步**：`settings.reading.analysisCheckpoint` 只有本地預設，未進同步快照，也沒有設定面板 UI 開關。
8. **發布步驟未執行**：依專案規範，部署前仍需執行 `node scripts/update-release-map.mjs` 更新靜態模組 import map；本輪未部署，因此未改。
9. **`article-version-ownership.cjs` 曾為既有失敗**：本輪已修復並重跑通過；若其他會話同時改動 tooltip，需再回歸。
