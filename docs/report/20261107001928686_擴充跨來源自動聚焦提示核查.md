# 擴充跨來源自動聚焦提示核查

時間：2026-11-07T00:19:28.686703+08:00。

## 結論

截圖訊息 `Blocked autofocusing on a <input> element in a cross-origin subframe.` 代表 Chrome 阻擋跨來源框架內的 HTML 自動聚焦。它會阻止自動放置輸入游標，並以 Security／Error 級別寫入瀏覽器記錄；不是查詞或 AI 請求本身的失敗。

目前交付的 0.6.0 安裝包與工作區的 `extension/lookup.html` 位元組一致，兩者均沒有 `autofocus` 屬性。此次沒有修改應用程式或重發版本；新增了可重複執行的焦點回歸測試。

## 驗證

新增 `tests/extension-focus.cjs`，使用真 MV3 擴充、真 Worker／SQLite、受攔截的 HTTPS 文章頁及既有 AI mock。源網頁與擴充 iframe 為不同來源，使用真滑鼠開啟查詞、編輯、設定與助手。

## 使用者端處理

1. 在 Chrome 擴充套件管理頁重新載入目前交付的 BDC 0.6.0 資料夾。
2. 重新整理原本的 BBC／閱讀網頁，讓舊 iframe 及 content script 重新載入。
3. 在該擴充的 Errors 清除舊記錄，再重新查詞。

根據目前安裝包與重測，截圖較可能是之前保留的錯誤記錄，或原網頁尚未重新載入的舊程式；這屬推斷，僅憑截圖不能直接核對使用者實際載入的安裝資料夾及記錄產生時間。
