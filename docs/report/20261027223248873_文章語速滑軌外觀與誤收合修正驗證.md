# 文章語速滑軌外觀與誤收合修正驗證

## 問題與修正

點擊語速面板的標籤或留白時，原有 `focusout` 處理會因焦點移走而立即收起面板。已改用面板外的 `pointerdown` 判斷：面板內點擊、調速，以及從面板內開始並在外面放開的拖動均保持展開；點擊外部、再次點擊倍速或按 Escape 才收起。

滑軌原先繼承全域輸入框的聚焦陰影，產生多餘的大方框。已清除該邊框與陰影，使用旋轉的原生 range 呈現 4px 直向軌道及小圓點，保留鍵盤操作與圓點的鍵盤聚焦提示；倍速按鈕固定寬度，避免調速時面板移位。

本次主要變更：`features/article/article.js`、`index.html`、`styles.css`、`tests/article-reading-layout.cjs`。沒有新增翻譯鍵。
