## 部署交付

請使用 [逐步部署與維護手冊](../release/20261018025155000_AI供應商逐步部署與維護手冊.md)。順序為：備份 → D1 結構 → 管理員與 secrets → Worker → 私密副本整理與掃描 → 新版前端 → 發布預設列表 → 一般使用者驗收 → 撤銷舊共享 Key。

後續列表、模型、任務及供應商 Key 透過管理介面發布，不需修改前端配置。現行方案仍是瀏覽器直連；登入使用者可以取得並複製共享 Key，並非服務端隱藏 Key 的代理方案。
