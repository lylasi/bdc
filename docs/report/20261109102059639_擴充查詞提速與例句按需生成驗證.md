# 擴充查詞提速與例句按需生成驗證

已完成 0.6.8 本機實作及安裝包封裝。使用者在設計訪談後回覆「全部按建議」：首次保留音標、詞義及簡短用法，沿用目前模型與思考設定，例句點開後才產生兩句中英對照並快取。

設計依據見 [已確認的設計訪談](../spec/20261109095640412_擴充查詞提速與例句按需生成設計訪談.md)。

## 最終行為

- 擴充套件的短語首輪 AI 回覆只要求音標、詞義及一項簡短用法，移除例句及重複回傳的原句／語境；原文語境仍用於判斷詞義。單字查詢沿用既有精簡路徑。
- 詞卡預設收合「例句」；首次點開才請求兩句，使用剛才查到的釋義、原句、語境及實際回應模型／思考設定。小窗顯示可用的簡短用法。
- 成功例句獨立快取；收合重開、關窗再開可重用。舊完整查詞快取已有的例句也可以直接顯示。沒有點開時不發出例句請求。
- 生成中重複展開不會多發請求；失敗只在例句區顯示可重試提示，已顯示的詞義仍可使用。
- 更換詞語、語言、帳戶、端點或重新查詞時，舊例句會取消或被丟棄。供應商連線在生成期間變更，也不能接受或快取舊連線的遲到結果。
- 文字查詞仍等待目前帳戶的 AI 設定、catalog 與個人憑證同步，但毋須等 TTS 憑據請求。登入及手動同步仍維持原本等待語音設定的行為。
- zh-CN、zh-HK 同步完成載入、失敗及重試文案；介面切換不轉換原文內容。

## 程式與快取

主要變更位於 `extension/lookup.js`、`lookup.html`、`lookup.css`、`modules/extension-ai-runtime.js`、`modules/api.js`、`modules/prompts/` 及兩份 locale。版本與 README 已更新至 0.6.8。

精簡短語快取以 `includeExamples: false` 區分；完整查詞可供精簡模式讀取，精簡結果不會取代主站需要的完整詳解。主站短語詳解的提示與預設例句需求保持原有行為。

新例句快取 namespace 為 `lookupExamples`，有效期 30 天，沿用 IndexedDB 優先、localStorage 後備及既有快取清理機制。鍵包含帳戶、同步端點、供應商／模型及上游連線、managed catalog 版本、思考、locale、詞語、釋義、原句、語境、提示詞版本及 schema。快取內容只含中英例句，不含 Key，也不新增學習快照欄位。

## 速度結論與界限

已證明新短語可以在 TTS 憑據請求仍未放行時顯示詞義，並且首輪請求不要求例句。這移除了例句輸出及無關 TTS 等待兩項延遲來源。這次沒有對真實 AI 供應商量測提速百分比；實際等待仍受所選模型、思考設定、AI 設定同步及網絡影響。
