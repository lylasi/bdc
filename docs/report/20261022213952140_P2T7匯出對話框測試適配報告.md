新增檔案 `tests/helpers/reading-export.cjs`（新檔，未納入任何產品模組）：

```js
async function exportReadingNote(page, {
    fullText = false,
    chat = false,
    fullBackup = false,
    selector = '#reading-export-md'
} = {}) {
    const downloadPromise = page.waitForEvent('download', { timeout: 30000 });
    await page.click(selector);
    await page.waitForSelector('.options-modal-overlay #confirm-btn', { timeout: 10000 });
    for (const [key, desired] of [['fullText', fullText], ['chat', chat], ['fullBackup', fullBackup]]) {
        await page.evaluate(({ key, desired }) => {
            const box = document.querySelector(`.options-modal-overlay input[type="checkbox"][data-option-key="${key}"]`);
            if (!box) throw new Error(`export scope checkbox missing: ${key}`);
            // 開關的 input 在對話框內是 0×0 疊在 label 上，改用 DOM click 才穩定。
            if (box.checked !== desired) box.click();
        }, { key, desired: !!desired });
    }
    await page.click('.options-modal-overlay #confirm-btn');
    return downloadPromise;
}

module.exports = { exportReadingNote };
```

實作要點：

1. 先建立 `waitForEvent('download', { timeout: 30000 })`，避免「先按確認才等下載」漏接事件。
2. `waitForSelector('.options-modal-overlay #confirm-btn')` 確認對話框已開。
3. 依參數設定 `input[data-option-key="fullText"|"chat"|"fullBackup"]`；已勾就不重複點（`box.checked !== desired` 才 `click()`），全未指定時維持產品預設 note-only。
4. 對話框內 `.switch input` 於 `styles.css:4851` 為 `opacity:0; width:0; height:0`，Playwright 可見性點擊會失敗，故採 `page.evaluate` 內的 DOM `click()`（與 `tests/article-download-export.cjs` 既有 `setDialogCheckbox` 一致的做法）。
5. 缺少選項時直接拋錯，不靜默降級（避免未來對話框結構改變時測試假通過）。
6. 回傳 `Promise<Download>`，呼叫端仍可 `download.saveAs()`／讀取內容。
