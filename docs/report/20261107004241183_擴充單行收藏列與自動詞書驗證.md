# 擴充單行收藏列與自動詞書驗證

日期：2026-11-07 00:44:09 CST；版本：0.6.1。

## 完成行為

- 詞卡底部合併成單行「加入詞書＋詞書圖示」，移除常駐選單及另建頁書收藏按鈕。成功狀態沿用同一列；錯誤與待傳仍可見。
- 新開詞卡先找同一原文網址的本頁詞書，再找無來源網址且名稱為「网页／網頁／网页生词／網頁生詞」的既有詞書。沒有後備時，第一次點擊加入才建立「網頁」，不改動帳戶原有預設設定。
- 手動選書在當前面板有效；重開、換頁或換帳戶恢復自動規則。下拉第一項可恢復自動選擇。已刪除的選中目標會停止收藏並要求明確改選。
- 點底部詞書圖示開原生對話框，選書、建本頁詞書、自訂建書、重新整理及直接查看詞書均在此操作。較少使用的帳戶預設設定收在「更多」。
- 首次建書使用既有耐久待傳與回執機制，並按帳戶及端點串行處理同時建立；沿用查詞結果，不再次請求 AI。原句、原文網址與定位保留。
- 補上不同對話框交接期間的關閉事件保護，避免舊事件改變已開啟對話框的版面。兩語介面均已補齊。
