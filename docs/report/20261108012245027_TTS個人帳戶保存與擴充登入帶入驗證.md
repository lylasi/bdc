# TTS 個人帳戶保存與擴充登入帶入驗證

版本：擴充套件 0.6.7；網站資源 `a82b70626b94`。本次針對「Pen子背單詞個人設定是否包含 TTS，以及登入擴充後自動帶入」完成保存、遷移及恢復流程。

## 設定入口與首次使用

1. 瀏覽器工具列點拼圖 → BDC 網頁查詞 → 首頁右上角的**雙滑杆設定圖示**（在另開分頁圖示旁）。
2. 設定窗中，介面語言下方就是「語音 / TTS」，點擊該列展開。
3. 網頁上的查詞卡亦可直接開啟：卡片頂部**鉛筆右邊、× 左邊**的雙滑杆，或點詞義下方的聲音來源文字。
4. 主站：右上角設定 → 全局設定 →「語音朗讀」。
5. 首次升級後，在已登入的主站重新整理一次，等待「已儲存到目前帳戶」。主站會把原本遠端服務配置及舊本機設定補存到帳戶；擴充套件登入同一端點、同一帳戶後會自動帶入。原來的瀏覽器本機資料要經過這次主站載入，才能完成首次遷移。
6. 擴充裏可按「試播並檢查」。綠色服務播放成功連同主機與聲音，代表服務已開始播放；裝置後備與回退原因仍會明確顯示。

服務欄填基礎地址，不附加 `/tts` 或 API Key 查詢參數。地址會統一處理大小寫及尾斜線。更新原本載入的 `extension/` 同一路徑後重新載入擴充，再重新整理閱讀網頁。

## 原有保存範圍

程式碼核對確認，舊版主站及 0.6.6 擴充的 TTS 地址、聲音、Key 只存在目前瀏覽器的設定／secrets；帳戶快照的 AI 群組不包括 TTS。正式 D1 的唯讀統計亦顯示：2 個現有帳戶快照，TTS 群組數為 0，與程式碼結論一致。[唯讀統計](assets/20261108012245027_tts-account/live-tts-presence-before.json)。

因此舊版的「已自動保存」代表當前瀏覽器保存成功，不能用來判斷 TTS 已經保存到個人帳戶。新版另外顯示帳戶同步狀態；離線或同步失敗時保留本機修改並顯示待同步／失敗，不誤報為雲端已保存。

## 現在保存甚麼

| 項目 | 保存方式 |
| --- | --- |
| 服務來源及遠端／本地／自訂基礎地址 | 個人帳戶 `ttsSettings` 公開設定群組 |
| 四組服務聲音及英語／中文朗讀偏好 | 隨帳戶同步，登入擴充自動恢復 |
| TTS API Key | 既有個人加密憑據通道的專用 TTS 槽位；D1 AES-GCM 密文儲存，普通快照不包含 Key |
| 裝置 voice URI、擴充「只用裝置語音」模式 | 留在目前裝置，避免把某部電腦的聲音名稱當成其他裝置的聲音 |

本機 TTS profile 按同步端點及使用者隔離。舊本機資料只遷移給第一個帳戶，已有雲端設定優先；新裝擴充的空白設定不會覆蓋主站。換帳戶或端點、登出、舊請求遲到及欄位自動儲存尚未完成時，均會檢查歸屬。

TTS Key 綁定當前服務地址，更換地址會清除其有效使用值，不能把舊服務 Key 發給新地址。清空個人 Key 會刪除雲端密文並保留版本墓碑；晚到的 401 不會登出另一個新帳戶。並行 Key 修改採版本檢查及 mutation id，遺失回覆可確認重放；真正的遠端衝突會保留本機輸入，使用者按重新同步才覆寫遠端版本。

普通快照及服務端均只接受白名單 TTS 公開欄位。TTS 使用既有加密個人憑據儲存的保留槽位 `bdc-tts-v1`，與 AI 供應商列表分開處理；復用已部署的憑據協議以相容現有 Worker，不新增資料庫表或遷移。selfhost 目前沒有該憑據接口，地址與聲音仍可同步，Key 會留在本機並明示不支援。
