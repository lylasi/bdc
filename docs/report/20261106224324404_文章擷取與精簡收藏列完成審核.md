產品提交：`1a61ab7`（文章預查容錯、精簡收藏列）、`da6267e`（清除恢復詞書的殘留錯誤）。主站 release `fe3f47277181`，97 個 ES Modules。

## 行為與審核

文章擷取前會查雲端已有文章。以前此預查只要失敗，AI 就完全不會執行；現在非認證網絡、逾時、服務錯誤允許先生成可編輯預覽，提示保存時再確認。預查支援取消，逾時為 6 秒。HTTP 非 JSON 回應仍保留 status，401／403 不會被誤當作可忽略的預查錯誤。查到文章但關聯時已刪除，會回到可擷取的流程。

保存沿用原有去重、不可變待傳、雲端回執及頁書關聯。服務仍無法連線時不顯示保存成功；恢復後重試不重跑已完成的 AI。401 清除帳戶及舊預覽；403 中止本次 AI，但保留本地草稿及帳戶，因權限拒絕本身不表示 token 失效。

收藏區一般狀態只保留「詞書選單＋加入＋⋯」，實測高度 39.2px。新建、本頁／預設詞書、刷新及來源收進省略選單，錯誤與待傳仍直接顯示。成功以「已加入」按鈕表示，避免重複提示佔高；切換詞書後不沿用舊成功狀態。空書單仍能新增並加入。快取書單未包含剛建立詞書造成的舊錯誤，在有效詞書恢復或重新選取後會清除，其他提示保持原有邊界。

完整面板按內容調整高度，仍固定右上並保留長內容捲動及草稿關閉保護。320／340／420px 與兩語介面已驗證。

## 實測界線

已定位並修復的是「單一輔助預查失敗阻塞全部擷取」的客戶端機制。截圖不足以確認使用者當次網絡、瀏覽器或服務端故障的觸發原因。正式無 token 的 401／CORS 回應不足以驗證正式認證後業務路由及 D1 schema；本輪不作該聲明。AI 使用隔離 mock 驗證請求及流程，沒有以正式帳戶或正式 AI 成功作為測試證據。

本次不需要 Worker、D1 或服務 schema 變更。後端全量文章掃描與網址查詢形狀可另作效能評估，沒有證據認定它們導致了使用者當次錯誤。
