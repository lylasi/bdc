# 句子解析原文複製按鈕驗證

英文原句右側新增「複製原文」按鈕。按下後只複製原句文字，並顯示成功提示；載入中、解析完成、重新擷取、重開已保存解析及解析失敗時均可使用。瀏覽器 Clipboard API 不可用或拒絕時會嘗試後備複製方式，失敗則提示手動複製。後備方式會清除暫存文字欄並恢復鍵盤焦點。
