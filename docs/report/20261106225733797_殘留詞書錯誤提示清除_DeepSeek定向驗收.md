### 3.5 額外觀察（不設通過門檻，只記錄）

**有待傳提示時建立詞書**（I4-觀察，同樣用閘門量「快取 pass 那一刻」與「網路回應後」）：

| 時點 | 提示 | 選取 |
|---|---|---|
| 快取 pass（網路被按住） | 「尚未确认收藏结果…」（**沒有**被暫時的 targetMissing 覆蓋） | `book-2` |
| 網路回應後 | 同上，仍保留 | 新書 `webbook_92fb1d…` |

原因（讀碼＋實測相符）：`restoreChoice()` 的候選順序是 `[previous, 目前選取值, 本頁頁書, 預設書]`；此時「目前選取值 `book-2`」本身就是有效書，所以第二步就選中了，`previous && !selected` 不成立 → 根本不會 raise。上一輪 §8.2 會 raise，是因為那一刻**沒有任何**有效選取可退回。

1. **403 不登出、保留本地預覽**：已由你審核接受（拒絕權限 ≠ token 失效），本輪維持原狀；全套中的 B3 仍確認「403 時 AI 0 次、不會顯示成功文案」。
