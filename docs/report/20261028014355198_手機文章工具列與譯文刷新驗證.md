# 手機文章工具列與譯文刷新驗證

日期：2026-10-28（Asia/Shanghai）。基線：`658063ab36aa724c13b54e1c8a529c01fa929c6e`；發佈資源版本：`3d9ab3f1165f`，86 個 ES Module。

## 行為

- 閱讀工具列保持單行；播放、停止、倍速固定保留。按實際可用寬度逐項將文章庫、匯入、閱讀記錄、側欄及輸入收到「…」，寬度足夠便還原。
- 移動原有按鈕 DOM，保留事件、閱讀記錄數量、雙語標籤、輸入原文及側欄狀態；選單內顯示完整操作名稱。
- 更多選單支援觸摸、鍵盤、Escape、點擊外部及離焦收合，與輸入／倍速面板互斥。修正觸摸轉移焦點時提前收合而吞掉操作的問題。
- 完成段落的刷新移至譯文右側，英文使用完整欄寬；觸控刷新區至少 44×44px。處理中及失敗重試保留原有狀態列，單詞詳解刷新繼續保留。
- 刷新維持獨立於譯文遮罩，並置於模糊譯文上層；迷霧模式下清晰且可點。僅顯示英文時也可刷新。
