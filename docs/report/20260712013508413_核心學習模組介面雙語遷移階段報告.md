# 核心學習模組介面雙語遷移階段報告

## 1. 本批範圍

本批依計畫完成以下介面的主要雙語遷移：

- 共用 UI：生字簿選擇器空狀態、選項彈窗標題及確認／取消按鈕。
- Vocabulary：主頁標題、操作按鈕、無選中狀態、空生字簿狀態及首次匯入提示。
- Learning：主頁靜態文案、單字下拉空狀態、例句生成狀態、造句檢查提示。
- Dictation：主頁設定、操作按鈕、輸入提示、暫停／恢復、浮動控制、完成及答題結果。
- Quiz：主頁設定、題型、進度、分數、問題文本、完成評語及進行中語言刷新。

## 2. 語言切換行為

- 大陸簡體使用「單詞本、聽寫、正确、错误、复习」等用詞。
- 香港繁體使用「生字簿、默書、正確、錯誤、溫習」等正式書面用詞。
- 學習內容、單字名稱、中文釋義及使用者輸入保持原樣。
- Learning、Dictation、Quiz、Vocabulary 在收到 `bdc:locale-change` 後刷新動態狀態。
- 進行中的 Quiz 會重新產生目前問題的介面文字，但不改變答案及題目資料。

## 4. 已修復的切換問題

- Dictation 暫停按鈕曾以 `textContent` 覆蓋靜態翻譯節點；現改為每次按狀態使用 `t()`。
- Dictation 浮動控制及展開列表會在切換語言後刷新。
- Quiz 問題原本在生成後固定為單一語言；現保存題型及目標資料，切換時重新本地化問題文字。
- Learning 下拉選單及空狀態會在切換語言後重新建立。
- Vocabulary 無選中及空列表狀態會在切換語言後重新渲染。
