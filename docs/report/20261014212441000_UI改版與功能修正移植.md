## 三、新增的開發伺服器 `scripts/serve.py`

改版的 AI 與導入依賴同源路由，`npx serve .` 沒有這些路由。因此新增：

```bash
python3 scripts/serve.py                      # http://127.0.0.1:8313/
python3 scripts/serve.py --lan                # 綁 0.0.0.0，手機／平板可用
python3 scripts/serve.py --ai-proxy http://127.0.0.1:3425
```

| 路由 | 用途 |
| --- | --- |
| `/v1/*` | 轉給 `--ai-proxy`，繞開網關的 CORS／來源白名單 |
| `/fetch?url=` | 伺服器端代抓 HTML |
| `/extract?url=` | 伺服器端代抓並轉成 `{title, markdown}` |

兩條抓取路由有 SSRF 防護（只允許 http/https、拒私網／loopback／link-local／保留位址、逐次轉址重檢、限大小與逾時），可用 `--no-article-fetch` 關閉。用 `npx serve .` 仍可跑，只是導入會退回第三方服務。
