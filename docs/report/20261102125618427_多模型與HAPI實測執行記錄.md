## Task 2

正式矩陣排程為256次；HAPI／Magpie各自保留渠道與模型欄位、相同題目hash、none/high請求值及觀測證據。後續分類會標記計數矛盾、仍在思考及缺乏可驗證資料，不把這些路徑稱為真正關閉。

觀察：HAPI420的習語none請求90秒逾時，部分內容出現大量不合理例句；同題high缺少完整JSON結尾。HAPI43另有長政策翻譯的格式錯誤。主測沒有重試或掩蓋這些失敗。Gemini高檔長政策翻譯一次約69秒，none同題約6秒，將另列單題耗時與中位數範圍。

- 主對照256次完成，227次完整成功，29次失敗均來自HAPI兩條fast路由；其他6路由192/192通過直接結構／完整性要求。
- 非流式20次完成：HAPI12次全部空正文，DeepSeek與GPT共8次成功。失敗沒有併入成功時延中位數。
- 計時後健康檢查3次：HAPI420／43只回空正文；Chat Fast雖有正文但不遵守只回OK，內容不相關。額度接口顯示unlimited=true且未過期，不把total_available=0誤判為餘額耗盡。具體上游故障原因未確定。
- 增加6次Magpie自有session的唯讀路由核驗：DeepSeek保留none；GPT、Gemini、Claude、GLM、MiniMax均顯示低檔。Gemini實際served為 `gemini-3.8-flash-n`，只記錄此特殊路由，不由字尾猜測零推理的普遍保證。故GPT／Gemini即使樣本無推理，也不會直接稱為真正關閉。
- 兩個匿名評審在全部計時結束後獨立並行：主評全部256份，次評固定抽48份，均已完成。原始主評32次、次評12次請求分別保存。
- 執行代理覆核119條待查，包括95份非空扣分及24份空正文，另抽查4份滿分代表答案。兩個相差1分的評審分歧均已核對部分分數的依據；保留主評及次評原始資料，作者10項記錄另存，9項改分、1項只移除錯誤的篇幅理由。
- 程式核對兩份被稱超過350中文字的答案實為310及318個漢字；接受等價的正確數學變化，不強迫逐字重述初末數字；少量英文術語配中文說明採一致標準。未因評審分數較高就把錯誤答案視為正確。
- 較晚冷卻再查HAPI3次，兩條fast仍空正文，Chat Fast返回1071字元不相關內容；健康檢查不併入品質與計時排名。兩輪共6次。
- 最終量測／評審總數396；256個唯一主測格、227次完整成功、主評256份、次評48份及資料映射已驗證。量測工具7/7通過，JavaScript獨立覆算64個任務／檔位耗時群組與Python一致。

Task 2: complete。主測失敗保留，HAPI29次失敗為24次空正文、4次非法JSON、1次90秒逾時；不把這些故障當成官方Grok能力結論。
