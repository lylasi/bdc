## 5. 测试中发现并修复的问题

1. **Article Cleanup 使用错误 Provider**
   - 原因：静态 `DEFAULT_MODEL` 覆盖任务模型映射。
   - 修复：任务模型优先，带 Provider 的模型不再注入旧静态连接。

2. **OCR 与听写图片批改使用错误 Provider**
   - 修复：`ocrExtractTextFromImage` 与 `aiGradeHandwriting` 统一使用任务配置。

3. **旧词书缺少 `word.id`**
   - 现象：学习下拉选项值为 `undefined`，例句与造句按钮不执行。
   - 修复：加载时补齐稳定 ID，并将旧 `definition` 迁移到 `meaning`。

4. **词书缺失音标显示 `/undefined/`**
   - 修复：仅在存在音标时渲染。

5. **动态界面存在繁体残留**
   - 已修复 Vocabulary 补全、OCR 图片头、Article 完成状态与句子解析、QA 设置/反馈/预览/PDF 按钮、听写批改历史等路径。

6. **批改历史局部变量覆盖 `t()`**
   - 现象：存在历史记录时弹窗报 `TypeError: t is not a function`。
   - 修复：时间字符串变量改名为 `timeText`，简体与香港繁体均已实测通过。

## 8. 最终评估

当前语言功能已满足以下核心要求：

1. 网页默认使用大陆简体中文。
2. 用户可切换大陆简体与香港繁体界面。
3. AI 依据当前界面语言返回对应中文。
4. 香港繁体使用香港正式书面用词，不按台湾用语设计。
5. 界面语言与学习内容语言解耦，不自动改写教材、OCR 原文、文章、QA、用户输入或历史消息。
