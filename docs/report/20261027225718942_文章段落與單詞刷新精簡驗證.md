- 已完成段落移除整行「完成／重新獲取」底欄，改為原文右上角的小刷新圖示，保留提示文字、無障礙標籤及鍵盤操作。觸控裝置放大點擊範圍，原文預留空間避免遮字。

- 刷新中禁止重複提交；失敗可再次重試。延遲回應不會覆蓋其他選詞、文章版本或帳戶，切換單詞後完成的刷新仍會更新原單詞資料。
