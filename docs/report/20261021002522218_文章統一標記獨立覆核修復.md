## 3. 修復內容

### 3.1 `modules/reading-store.js`

- `ensureArticleReadingLoaded()`：遷移結果為 `{ok:false}` 時**回傳失敗**（`error: marked_migration_failed`），不加入 `loadedArticleIds`，保留交易式冪等重試；只有成功才標記已載入。
- `findPhraseItem()` 增加 `contentVersion` 參數。
- 新增 `findUnpositionedItem()`：只找 `anchor.start < 0` 的舊條目，供「位置未知」的相容路徑使用。

### 3.2 `modules/reading-actions.js`

- `resolveAnchor(..., bodyOverride)`：可用**凍結的內文**算錨點。
- 新增 `anchorFromOffsets(articleId, quote, start, end)`：由按鈕自帶的精確 offset 重建錨點；內文不再對應時回 `null`，不退回文字搜尋。
- `findSavedItem(articleId, kind, quote, sentence, { anchor, contentVersion })`：
  - 有精確 anchor 時**只**按「同一錨點＋同一版本」查；
  - 只有當引用在內文僅出現一次時，才允許用「位置未知」舊條目接手；
  - 同一段文字出現多次時直接回 `null`，不再猜另一處。
- `recordExplanation()` / `ensureItem()` 新增 `contentVersion` 參數：呼叫端必須傳入請求／選區建立時凍結的版本，函式內不再重算（未傳時才 fallback 為現行版本，僅供舊呼叫點）。

### 3.3 `features/article/article.js`

- 新增單詞彈窗 session：`wordTooltipSession` / `wordTooltipContext`。點擊當下凍結 `actionContext`、`articleContextSnapshot`、`contentVersion`、`wordAnchor` 與 `stillShowing()`。
  - `.then()` 成功路徑：先以**凍結版本＋凍結錨點**保存解釋（`markViewed: stillShowing()`），`saveAnalysis(..., { ctx: 凍結 ctx })`，最後 `if (!stillShowing()) return;` 才重繪。
  - `.catch()` 失敗路徑：同樣先檢查 `stillShowing()`，避免舊錯誤蓋掉新選詞。
  - 快取命中分支改為 `showTooltip(data, sentence, paraEnglish, wordText)`，補回 sentence／context，並帶精確錨點與版本。
- `actionButtonsHtml()`：用本次點擊的 `wordAnchor` + `contentVersion` 查真實狀態，按鈕輸出 `data-anchor-start` / `data-anchor-end` / `data-content-version`。
- tooltip 動作委派：`readTarget()` 優先以 `anchorFromOffsets()` 還原精確錨點；`actionContext` 改用 `wordTooltipContext`（凍結），失效即 `stale_scope` 拒絕，不再於點擊時重抓。
- 句子詳解（modal／inline／refresh）與片語解析：請求開始即凍結 `actionContext`、`articleContextSnapshot`、`contentVersion`、整句錨點；`persistSentenceAnalysis()` / `persistPhraseAnalysis()` 接受並傳遞 `ctx`；`markViewed` 只在仍顯示同一篇＋同帳戶時為 `true`。
- 原生選區工具列：`captureSelection()` 增加 `contentVersion` 與 `actionContext`；新增 `syncBarState()`，每次 `showBar()` 都按「這一精確選區」重設標記按鈕文案與 `aria-pressed`；點擊改用凍結上下文並先驗證有效性。

### 3.4 `features/article/phrase-picker.js`

- 開啟面板時凍結 `contentVersion`。
- `currentTarget()` 改用 `state.articleBody`（凍結內文）＋ `sentenceStart + token offset` 算錨點。
- `ensureTargetItem()` / `currentItemForTarget()` / 筆記查找／問 AI 全部改用凍結版本。

### 3.5 `features/article/reading-panel.js`

- 卡片標記切換改傳 `captureActionContext()`，切換帳戶後不會把標記寫進新 scope（筆記草稿原本已帶 `draft.actionContext`）。
