# BDC 0.6.2：文章擷取先預覽，再確認匯入

日期：2026-11-07 01:32:12 CST。

## 操作流程

右鍵「AI 擷取匯入文章詳解」會開啟獨立彈出視窗，先整理標題及原文正文，並停留在可編輯的預覽。檢查及修改後，按「確認並分析匯入」才開始逐段分析翻譯，成功後加入文章記錄。確認前不會產生段落翻譯請求、新文章寫入或文章待傳工作。

預設勾選「確認匯入時逐段分析翻譯」。如取消勾選，按鈕會改成「確認並匯入正文」，同樣要按確認才寫入。成功後保留完成狀態，按「在 BDC 開啟」才在同一個彈出視窗開啟文章。關閉未確認預覽不會建立文章。

既有文章會沿用原記錄並顯示開啟入口；已確認的耐久待傳仍保留原有重試行為。原文網址、頁面 ticket 綁定及文章詞書關聯維持有效。

## 修改

- `extension/workspace-ui.js`：快捷入口只做提取；分析與寫入集中在獨立確認按鈕。預設分析選項及按鈕文案一致。
- `extension/lookup.html`：加大正文編輯區，提供確認後分析翻譯的明確選項。
- `locales/zh-CN.js`、`locales/zh-HK.js`：補齊正文待確認、確認分析匯入及只匯入正文文案。
- `modules/api.js`：空譯文不寫入成功快取，讀取時略過舊的空白／失敗快取，避免提供者傳回空物件後重試一直命中空結果。瀏覽器測試已重現修正前的問題，並驗證失敗後重試成功。
- 更新 manifest 至 0.6.2，README 及 import map 同步更新。
