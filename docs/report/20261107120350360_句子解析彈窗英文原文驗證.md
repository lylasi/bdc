# 句子解析彈窗英文原文驗證

句子解析彈窗現於中文譯文上方顯示英文原句。載入中、解析完成、重新開啟已保存結果、重新擷取及解析失敗時均保留原句。原句直接取自文章，經 HTML 跳脫後顯示，不採用模型改寫的句子。
