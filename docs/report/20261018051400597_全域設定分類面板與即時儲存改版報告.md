# 全域設定改版：分類面板、即時儲存與版面整理報告

日期：2026-10-18（Asia/Shanghai）
範圍：全域設定彈窗（`features/sync/sync.js`）、設定持久化（`modules/settings.js`）、共用樣式（`styles.css`）、modal footer（`index.html`、`modules/ui.js`、`modules/dom.js`）。

## 1. 需求與背景

使用者反映：

1. 設定項太多，每一個都要按底部「儲存」才能生效，太繁瑣；希望選模型、改 TTS 等操作當下就保存。
2. 設定介面可以再美化，參考 magpie 的做法。

magpie 是 macOS 上的原生（Wails）應用，無法直接沿用其程式碼；可借鏡的是它的資訊架構與互動習慣：**左側分類 + 右側面板、改動即生效、底部只有關閉**。本次改版照這個方向實作。

## 2. 改版結果

### 2.1 版面

- 彈窗內改為左右兩欄：
  - 左側固定分類列：`介面`、`語音朗讀`、`AI 供應商`、`助手與工具`（sticky，視窗內捲動不消失）。
  - 右側對應面板：卡片式分組，標題／說明／控制項層次固定。
- `≤820px` 時分類列改為貼齊邊緣的橫向卷軸（不會透出下層卡片內容）。
- 底部固定列（`#modal-actions`）只有 `已自動儲存 · 時間` 與 `完成`；移除「儲存／取消」。
- 分類可用滑鼠或鍵盤操作（`←/→` 在水平版、`↑/↓/Home/End` 在垂直版切換）。

### 2.2 即時儲存

下列操作都在當下寫入 localStorage，並在底部顯示「已自動儲存」：

| 分類 | 選項 | 寫入位置 |
| --- | --- | --- |
| 介面 | 顯示語言 | `pen_global_settings.language.interfaceLocale`（同步套用 `setLocale`） |
| 介面 | 配色主題 | `pen_global_settings.theme`（立即 `applyTheme`） |
| 語音朗讀 | TTS 來源（遠端／本機／自訂） | `tts.use` |
| 語音朗讀 | 自訂 TTS URL | `tts.baseUrlCustom`（輸入 debounce 700ms，失焦立即寫入） |
| 語音朗讀 | TTS API Key | `pen_global_secrets.ttsApiKey`（debounce 600ms，關閉面板前會 flush） |
| 語音朗讀 | 英語／中文朗讀偏好 | `reading.englishVariant` / `reading.chineseVariant` |
| 語音朗讀 | 四個語音清單選擇 | `tts.selectedVoices` |
| 助手與工具 | 拼讀開關 | `phonetics.enabled` |
| 助手與工具 | 助手 / 串流開關 | `assistant.enabled` / `assistant.stream` |
| AI 供應商 | 任務模型、預設模型 | 原本就即時寫入 AI profile（未改） |

介面語言變更後，面板會**在同一彈窗內重建**（保留目前分類），不需要關閉再開。

### 2.3 一併修掉的持久化 bug

`modules/settings.js` 的 `saveGlobalSettings()` 之前寫回 localStorage 時只做 `{ ...stored, ...patch }` 的淺合併：

```js
saveGlobalSettings({ tts: { use: 'local' } });      // tts 只剩 { use }
saveGlobalSettings({ tts: { baseUrlCustom: '…' } }); // use 被蓋掉
saveGlobalSettings({ tts: { selectedVoices: {…} } }); // baseUrlCustom 又被蓋掉
```

在「一個欄位一個欄位即時儲存」之後，這個問題會直接讓設定互相覆蓋。已改為 `mergeStoredSettings()`：`language`、`tts`、`reading`、`assistant`、`phonetics` 逐層合併（`tts.selectedVoices` 再往下一層），AI 區塊仍依原本的遷移規則處理。

### 2.4 Modal 版面順序修正

`styles.css` 原本有全域 `main { … order: 2 … }`（以及 `@media` 內的 `main { order: 3; padding-bottom: … }`）。`#modal-body` 本身就是 `<main>`，因此：

- 彈窗內容被排到空的 `#modal-actions` footer **之後**；
- 每個彈窗都多了一段給底部標籤列預留的 padding。

已把四條 `main` 選擇器收斂為 `.app-layout > main`，並把 `#modal-actions` 改為預設 `hidden`、由 `closeModal()` 清空，只有需要固定底部列的面板（全域設定）才填入內容。登入、詞書等其他彈窗也因此少了空白 footer。

### 2.5 樣式來源整理

- 移除 `sync.js` 內注入的 `gs-asst-style`（`.gs-toggle`、`.gs-hint { margin-left:auto }` 等），統一由 `styles.css` 管理。原本右對齊的提示文字（如語言說明）恢復正常左對齊。
- 新增 `.gs-shell`／`.gs-nav`／`.gs-card`／`.gs-choice`／`.gs-toggle`／`.gs-voice-grid`／`.gs-footer` 等樣式，全部使用既有設計令牌（主題切換含深淺色都不需要另外寫色碼）。
- `styles.css` 版本參數更新為 `20261018-settings-autosave`。

## 5. 已知邊界

- **AI 供應商表單仍需按「保存」**：新增／編輯供應商需要 URL、Key、連線與模型白名單一起驗證，屬於建立流程而非偏好設定；讀取、任務模型映射、預設模型本來就即時寫入。
- 切換介面語言會重建整個設定面板（AI 供應商表單的未保存草稿會重設）；語言切換本身是低頻操作，換來的是整份文案即時更新。
- TTS 金鑰與自訂 URL 為避免每個字元都寫入，使用 600/700ms debounce；關閉面板或按「完成」時會立即 flush。
- 參考 magpie 的是資訊架構與互動方式（分類、即時生效、只有關閉），未使用其程式碼或視覺資產。
