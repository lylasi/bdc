# 思考模式說明圖實作與驗證

計劃：`docs/plan/20261103001307283_思考模式說明圖實施計劃.md`。日期：2026-11-03。狀態：完成，未提交或部署。

## 完成內容

已在兩個入口加入帶ic-info圖片的「思考強度說明」：

1. 全域設定 → AI供應商 → 按功能指定模型。
2. 文章工具列／查詞彈窗開啟的快速模型視窗，位於思考選擇欄下方。

點擊圖示或文字可展開五檔對照圖，再次點擊收起。每檔包含名稱、作用及適用場景，低／中／高配以三段強度圖示；服務端預設與關閉使用不同圖形，避免暗示它們是同一種低強度。

- 跟隨服務端：沿用供應商或模型的預設行為，可能包含思考。
- 關閉思考：要求略過額外推理，通常較快；說明部分渠道可能改用最低強度。
- 低強度：少量分析，適合簡單問答及快速檢查。
- 中強度：在深度與等待之間平衡，適合句子分析及文章問答。
- 高強度：更多思考及通常較長等待，適合長難句、多步推導及核對。

快速視窗額外解釋「跟隨應用預設」與「跟隨服務端」的區別。圖末亦說明高檔不保證更正確、隱藏思考內容不等於關閉。

說明是可讀、可隨語言切換的向量圖示及HTML對照圖。支援zh-CN／zh-HK；只有一套功能程式碼。沒有新增持久化設定或修改任何推理預設。

設定改動或快速視窗切換任務後，已展開的說明會保留；查看、展開或收起說明不寫入AI profile，也不發起AI生成請求。
