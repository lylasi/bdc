# 擴充查詞發音入口實作與驗證

日期：2026-11-07T16:53:01+08:00。

使用者截圖的 0.6.4 詞卡只有音標，沒有發音入口。0.6.5 已在單詞旁加入一個喇叭圖示，按下播放目前查詢的單詞或短語；再次按下停止，播放完畢回復喇叭。保留原有精簡收藏列。

## 行為與實作

沿用 modules/audio.js 的 speakText、停止及音訊 owner 管理，擴充封裝補入該共享模組。未配置遠端 TTS 時直接使用裝置的英語語音，發音不發送 AI 查詢，也不等待詞書或帳戶同步。沿用已配置 TTS 的播放及系統語音後備機制；語音品質依裝置與供應商而定。

重新查詞、編輯輸入、開啟設定／助手、登出、關閉詞卡及頁面離開時停止發音。使用序號隔離舊播放回呼，避免先前的結束事件干擾新播放。語音失敗顯示簡繁對應提示，可以直接重試；介面語言不改寫英文朗讀內容。圖示有 title、aria-label 及播放狀態，沒有增加擴充權限。
