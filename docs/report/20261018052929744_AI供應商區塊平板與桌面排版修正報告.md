# AI 供應商區塊在平板／桌面的排版修正

日期：2026-10-18（Asia/Shanghai）
範圍：全域設定 → AI 供應商（個人供應商卡片、金鑰同步列、按功能指定模型）。

## 1. 問題

實際在 1024／834 寬度下（管理員已登入），AI 供應商區塊出現：

1. **「密鑰同步」被擠成兩行**：全域 `select { width: 100% }` 讓同步模式的 `<select>` 佔滿
   `<label class="gs-ai-inline">` 的寬度，前面的文字只能斷成「密鑰 / 同步」。
2. **供應商卡片只有一條垂直堆疊**：資訊、啟用／編輯／刪除、金鑰同步全部從上往下排，
   在 1000px 寬的彈窗裡留下大片空白，操作按鈕也沒有對齊。
3. **「按功能指定模型」每列高 76px**：`styles.css` 的通用
   `details > *:not(summary) { padding: var(--sp-4); }` 把每一個 grid 列都撐大，
   表單欄位也跟著內縮，跟卡片其他內容對不齊。
4. **任務列的下拉拉滿剩餘寬度**（1000px 彈窗裡約 480–500px），視覺上過寬。

## 2. 修正

### 2.1 供應商卡片

`renderPersonalList()` 的同步列改成「標籤 + select」兩個獨立元素（不再用一個 label 包住）：

```html
<div class="gs-ai-provider-sync">
    <span class="gs-ai-sync-label">密鑰同步</span>
    <select data-ai-syncmode="…">…</select>
</div>
```

`styles.css`：

- `.gs-ai-provider-row` 改為 2 欄 grid：
  `main actions` / `sync sync` / `delete delete`，資訊在左、操作靠右、金鑰同步另起一列。
- `.gs-ai-provider-sync` 加上虛線分隔、`select { width: auto; min-width: 190px; margin-left: auto; }`。
- `.gs-ai-inline`（啟用勾選）加 `white-space: nowrap`，不再被拆行。
- `≤700px` 回到單欄堆疊，同步下拉改為整行寬。

### 2.2 任務列與 details 內距

- 新增 scoped reset：

```css
#modal-body details > *:not(summary),
.ai-admin-panel details > *:not(summary) { padding: 0; }
```

  只影響設定彈窗與管理員面板；主站的 `dictation-advanced`、`ocr-advanced` 仍保留原本的 16px 內距。
- `.gs-ai-task-row` 改為 `minmax(120px,180px) minmax(0,380px)` + `justify-content: space-between`，
  標籤靠左、下拉靠右且不再拉滿整個面板。
- 管理員面板的任務列（三欄 grid）同步受益。

## 3. 驗證

以 mock Worker 登入（`role=user`／`role=admin`）在 390／834／1024 寬度實際截圖：

- 1024：供應商卡片為「資訊｜操作」兩欄、金鑰同步為一列，標籤單行；任務列高 44px、對齊卡片內緣。
- 834：同上，未出現橫向溢出或換行。
- 390：自動回到單欄，操作按鈕整排、同步下拉整行。
- 管理員面板（管理預設供應商）在 1024 下開啟正常，任務列沒有被 details 內距撐高。
- 登入／非登入、zh-CN／zh-HK 都檢查過。

## 4. 已知邊界

- 供應商卡片只做到「資訊／操作兩欄 + 同步列」，沒有把模型清單直接展開在卡片內；
  要看模型仍按「編輯」。
- `≤700px` 的門檻是依現有斷點與實際寬度測試選的；若之後加入更多欄位，需一併調整
  `.gs-ai-provider-row` 的 `grid-template-areas`。

## 5. 變更檔案

- `features/sync/ai-provider-settings.js`：同步列 markup（標籤與 select 分離）。
- `styles.css`：`.gs-ai-provider-row`／`.gs-ai-provider-sync`／`.gs-ai-task-row` 版面、
  `details` 內距 scoped reset、`≤700px` 斷點。
