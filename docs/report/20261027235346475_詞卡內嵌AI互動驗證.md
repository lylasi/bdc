# 詞卡內嵌 AI 互動驗證

驗證時間：2026-10-27 23:53:46（Asia/Shanghai）。測試地址：[文章詳解](http://127.0.0.1:8313/#a)。

## 完成行為

- 點擊單詞詳解內的 AI 圖示，在詞卡下方展開空白輸入框；輸入後才發送，可直接連續追問。
- 回答區最高 196px，約 6–8 行，超出後內部捲動。手機可視高度縮小時，回答區縮短，保留輸入框。
- 展開後點擊空白處保留詞卡；×、Escape 可關閉，點擊其他單詞可切換。
- 每個單詞的精確位置、原句及文章版本使用獨立會話。重新開啟可恢復對話；未送出的草稿在當頁保留，重載後不保留。
- 點擊放大圖示，移動同一組問答節點至大視窗；返回詞卡時保留歷史、草稿與進行中的串流，不另發請求。
- 保留停止及原問題重試；停止保存未完成的回答，重試使用原先文章與單詞背景。帳戶或文章版本失效時清理問答，防止舊請求寫入新範圍。
- 普通文章助手與詞卡會話分開；自動恢復普通助手時，不選取詞卡會話。
- 簡體及香港繁體共用功能，介面、無障礙標籤及「保留為文檔」操作狀態隨語言更新，不改寫原文、草稿或歷史訊息。

已確認的需求見：[詞卡內嵌 AI 互動規格](../spec/20261027233110751_詞卡內嵌AI互動規格.md)。
