# 文章逐句朗讀實作與驗證

## 完成內容

依使用者於三輪 grilling 中確認的方案，文章詳解的句尾解析圖示改為同位置、同排版尺寸的 `⋯`。手機每句仍只有一個常駐入口，按下後顯示四項操作：

| 操作 | 行為 |
| --- | --- |
| 朗讀本句 | 只讀指定英文句一次，然後停止 |
| 從這裏開始讀 | 由指定句起，逐句各讀一次，直至文章結尾 |
| 循環讀本句 | 持續重讀指定句，兩次之間停頓 0.5 秒，直到停止或切換 |
| 解析句子 | 進入既有解析流程；單純打開選單不觸發 AI |

電腦懸停句子時提供浮動朗讀捷徑，不參與正文排版；原有句尾譯文提示及中英句子聯動仍保留。英文句內選區的既有浮動工具列新增朗讀圖示，只讀選中的內容一次。

三種句子操作不受側欄「全文／段落／句子」及「重複次數」影響，也不改寫側欄原設定；聲音及語速沿用目前選擇。共用既有播放列的暫停、繼續、停止及前後句控制；前後句保留目前播放模式。

同句同模式再次操作會停止，換句或換模式會立即取代目前播放。循環的計時器會在停止、暫停、換句或其他音訊中斷時取消，避免已停止的朗讀再次出聲。暫停後繼續由本句開頭重播，結束新播放不會自動恢復被取代的全文播放。

## 程式變更

- `features/article/sentence-actions.js`：共用句尾選單、電腦浮動捷徑、視窗邊界定位、鍵盤導航、Escape 及外部點擊關閉、即時語言切換。
- `features/article/article.js`：句尾入口、三種播放行為、選取內容朗讀、循環與取消、共用播放列及模式提示。
- `index.html`、`modules/dom.js`：集中新增選單及浮動按鈕的 DOM 參照。
- `styles.css`：浮動選單及捷徑樣式；句尾入口保持原有 16px 排版寬度與擴大的點擊區。
- `locales/zh-CN.js`、`locales/zh-HK.js`：新增對稱的動作名稱、停止狀態、無障礙標籤及播放模式文案。
- `tests/article-sentence-reading.cjs`：新增整體互動與播放回歸測試。
- `tests/article-analysis-ownership.cjs`：調整句子解析的測試入口，經由新選單啟動解析。

播放模式沒有持久化，沒有新增 localStorage、同步 snapshot 或 AI 憑證欄位。

## 驗證限制

播放次序、循環及取消透過可手動完成的系統語音 mock 驗證，未向真實 TTS 供應商請求或評估聲音品質。手機排版使用 Chromium 觸控模擬；本次沒有宣稱已在實體 iPhone／Android 裝置完成驗收。


## DSH 獨立審查後修正

使用者指定的「測試界面審查 DSH」已完成首輪獨立審查，判定沒有阻擋級問題。發布前另修正 F1、F2、F3、F5：

- 中文原文段落的英文朗讀動作會停用，選單顯示原因；解析仍可用，電腦不再提供無效朗讀捷徑。無法在播放佇列定位的句子亦有提示。
- 自動捲動期間，只要句尾錨點仍位於視窗內，選單就重新定位並保持可用；錨點離屏時才關閉。
- Tab／Shift+Tab 依句尾入口附近的文章控制順序繼續導航；Escape 仍返回入口。浮動選單維持在正文之外，避免其文字被納入朗讀。
- 香港繁體文案改為「朗讀選取內容」。

F4 的跨模組繼續播放沿用既有背景播放策略，浮動停止控制仍可用，符合本次已確認範圍。

新版新增測試涵蓋可見錨點捲動、Tab／Shift+Tab，以及簡繁雙語的中文原文桌面／320px 四組情境，連同原六組共十組均通過。乾淨發布副本的字典各 2432 鍵，鍵集合及插值一致；資源版本統一為 `45e02639d310`（98 個模組）。原開發副本包含其他未提交工作，因此其字典及模組數與發布副本不同。

首輪報告：`docs/report/20261107033553134_文章逐句朗讀獨立審查報告.md`。四項修正已另交 DSH 在乾淨發布副本複查，複查與實際更新 149 的結果另記於發布紀錄。


DSH 發布前複查已通過：獨立斷言 106 + 16 + 7 = 129 項零失敗，產品測試十組全數通過，98 個映射模組及 HTML／CSS 內容逐一與發布磁碟吻合。可發布結論與邊界見 `docs/report/20261107034652978_文章逐句朗讀修正後發布前複查報告.md`。本次發布採用複查確認的 `45e02639d310` 資源版本。
