# 擴充套件 0.5.0：模型、思考選擇與 DSH 介面審核

Codex 開發及最終審核，DSH（DeepSeek Harness）美化小窗、完整面板及帳戶頁，DeepSeek 獨立功能驗證及修復後複測。產品提交 c700a8b、c9169df，README 更新 6ba69cc。

## 完成行為

- 小窗及設定頁可直接選帳戶允許的模型和五檔思考程度；查詞、文章擷取及段落翻譯依用途選擇。更改即時保存，下一次請求生效；可明確重新查詞或恢復帳戶設定。
- 偏好按 endpoint / user / task / field 分鍵，不包含憑證；重新開窗、同步及換回帳戶後保留。跨頁的不同用途、同用途不同欄位可同時更新，不互相覆寫。主站 AI profile 及 snapshot 不受這些偏好寫入。
- 舊快照只有 tasks 對應且 models 為空時仍能正確讀取；合併有效對應時 models 優先。供應商或模型被移除會顯示不可用及錯誤，可換模型或恢復帳戶設定。
- 思考參數被拒後沿用共用 AI 回退；首次降級會在收合詳情外顯示已使用服務端預設的提示，支援兩語，下一次操作及帳戶切換清除。
- DSH 統一字級、按鈕、間距、焦點及錯誤狀態，減少卡片和留白。帳戶登入後收合；必要狀態、缺 Key 提示、待傳入口仍可操作。完整面板的結果只保留模型及思考檔位資訊。
- 密碼、通行碼及本機 Key 欄位以有效的密碼輸入類型遮蔽。
