# MiniMax 語音免費額度與 API 計費核對

- 核對日期：2026-10-28。
- 問題：MiniMax TTS 的免費用量、發放週期、文字換算、到期規則，以及能否用於 BDC 的文章朗讀 API。
- 方法：閱讀官方公開文件，並以未登入的瀏覽器直接檢視 MiniMax Audio 現行訂閱方案及 FAQ；中國內地 API 另核對官方定價、前置準備、FAQ 及速率限制。
- 範圍：沒有登入、建立帳戶、申領獎勵、付費或呼叫實際語音生成 API；本次沒有修改 BDC 或 Kokoro 部署。

## 一、結論

**可直接確認的固定免費方案是 MiniMax Audio 國際網頁版每月 10,000 credits，官方估算約 12 分鐘 HD 語音。未查到 Open Platform API 對所有帳戶公開保證的固定每月免費語音額度，不能直接把網頁贈送積分當成 BDC 可呼叫的 API 額度。**

| 入口 | 已確認的免費資訊 | 對 BDC 的意義 |
| --- | --- | --- |
| MiniMax Audio 國際網頁版 | Free：US$0／月、10k credits、Monthly Gift、約 12 分鐘 HD | 適合透過網頁試聽；尚未確認這份積分可由標準 Open Platform API Key 扣用 |
| 官網英語 TTS 體驗頁 | 頁面顯示 5 次免費試聽 | 沒有公布每次字符量或重置週期，不能換算成 API 免費配額 |
| 國際 Open Platform 語音 API | 公開定價列按量收費，未找到固定每月免費字符承諾 | 若帳戶有贈額，須另看該帳戶／活動條款 |
| 中國內地 Open Platform 語音 API | 未找到固定的新戶、實名或每月免費字符承諾 | 官方「免費用戶 10 RPM」僅為速率上限，不代表免費總量 |

「未查到固定公開承諾」不等於所有帳戶都沒有活動贈額；目前無法替未登入的特定帳戶確認其餘額及到期日。

## 二、網頁版每月 10,000 積分能用多少

### 現行訂閱頁的直接證據

來源：<https://www.minimax.io/audio/subscribe>。

2026-10-28 直接檢視 Free 卡，顯示：

> Free · $0 /month · 10k Credits · Monthly Gift · ~12 mins of HD model · 3 Voice Slots

下方比較表亦列 Monthly Credits 為 10K、HD Model Duration 約 12 mins。頁面的歌曲數估算與語音分鐘數使用同一份積分，不能視作兩份可獨立用盡的免費額度。

FAQ「What is the conversion relationship between text and credits?」原文：

> The conversion between text and credits depends on the language you're using. In most cases, one English letter equals one credit, while one Chinese or Japanese character equals two credits. Check the specific conversion in the lower-left corner of the input box.

因此按這個一般換算，可粗估：

- 10,000 個英文字母；不是 10,000 個英文單詞。
- 或約 5,000 個中文字元。
- 精確扣點以輸入框顯示為準；上述 FAQ 沒有完整列出網頁版各模型倍率及所有標點、空格的規則。
- 官方約 12 分鐘 HD 是估算，不能同時保證上述各語言文字量一定會得到相同時長。

例如每篇有 1,000 個英文字母，約可生成 10 篇；每篇 1,000 個中文字元，約可生成 5 篇。這只是依 FAQ 的粗估，實際扣點仍以生成前顯示為準。

### 單次文字上限與總額不同

同頁 FAQ「How much text can I convert to audio at once?」表示：

> The character limit is based on your remaining credits, which are converted to characters according to the model's pricing. If the converted value exceeds our model’s maximum limit (5000 characters for HD or 10000 characters for Turbo), the maximum limit will be displayed instead.

即網頁單次上限為 HD 5,000 characters、Turbo 10,000 characters，並受當時餘額限制。這些數字是單次輸入上限，不能再當作額外免費用量。

### 每月發放與有效期

現行訂閱頁明寫 Monthly Gift，沒有支持「每天固定送 10,000」的證據。

[Audio 付費服務條款](https://www.minimax.io/audio/doc/paid-service-terms.html)最後更新為 2026-02-12，仍有以下文字：

> Free Users: Upon logging in, users may receive daily time-limited free credits ...

> All monthly credits expire at the end of each calendar month.

這份條款亦保留與現行訂閱頁不同的付費方案數字，顯示公開頁面未完全同步。因此：

1. 現行免費數量及週期以直接顯示的每月 10k 為依據；舊條款沒有承諾每天的具體數量。
2. 條款寫月度積分在曆月月底到期，不應假設未用完可以累積；實際免費贈額的發放日、到期日及任何額外活動須以帳戶顯示為準。
3. 不能把付費 top-up 的有效期套到免費積分。
4. FAQ 的 14-day Free Period 問題針對歌曲商用權，不能當成語音積分有效期。

「Will subscribing affect my new user bonuses?」FAQ 只確認會員可與新用戶獎勵疊加，沒有列出該獎勵的數量或有效期。

## 三、網頁試聽與 API 免費額度的界線

[官網英語 TTS 體驗頁](https://www.minimax.io/audio/text-to-speech/english)顯示：

> You have 5 free trials remaining.

> You have five free tries for generation.

這只證明該網頁提供初始試聽次數，沒有公開每次文字配額及何時恢復；不能用來推算 API 可免費呼叫五次。

Audio 舊條款的免費用戶段落曾提及有限 API service，但沒有說明現行網頁月贈積分是否與 Open Platform 餘額共用、適用哪種 Key、或可扣用多少。因此亦不能反過來斷言所有網頁免費帳戶完全沒有 API 權限。

國際 API 的[定價與計費文件](https://platform.minimax.io/docs/pricing/overview.md)明寫：

> With pay-as-you-go billing, you use standard Open Platform API keys and pay from your account balance based on usage.

> API usage charges are deducted from your account balance.

該公開文件未列出所有帳戶固定可領取的免費語音總量。BDC 若接入標準 API，目前應按計費服務估算成本；個別帳戶的活動贈額需要另外核對。

[同步語音 API 文件](https://platform.minimax.io/docs/api-reference/speech-t2a-http)的少於 10,000 characters 是單次輸入限制，並非每月免費額度。Audio 網頁 credits、API 資源包 points 與按量計費 characters 也不能在缺乏規則時直接當作相同單位。

## 四、API 按量價格

截至核對日，官方對同步及異步文字轉語音列出相同價格：

| 模型 | 國際站：每 100 萬計費字符 | 國際站：每 1 萬計費字符 | 中國內地站：每 1 萬計費字符 |
| --- | ---: | ---: | ---: |
| `speech-2.8-turbo` | US$60 | US$0.60 | ¥2.00 |
| `speech-2.8-hd` | US$100 | US$1.00 | ¥3.50 |

來源：

- 國際：<https://platform.minimax.io/docs/pricing/overview.md>。
- 中國內地：<https://platform.minimax.cn/docs/pricing/overview.md>。

中國內地官方明文列出字符計法：

> 1 个汉字算 2 个字符；英文字母、希腊字母、标点符号、特殊符号、空格、回车等各算 1 个字符。

據此，中國內地 API 的例子是：

- 一篇合計 10,000 個計費字符的英文文章：Turbo 約 ¥2、HD 約 ¥3.5。
- 10,000 個漢字本身：Turbo 約 ¥4、HD 約 ¥7，標點及空白另計。
- 反覆重新提交合成會產生新的用量；重播已保存的音訊不需要再次合成。BDC 是否有適用的音訊快取，屬接入設計，不能假定現有功能已處理。

上述為語音合成按量價，沒有加入另行收費的聲音複製、設計等功能。

## 五、中國內地免費額度核對

查閱官方前置準備、帳戶 FAQ、API FAQ、定價與速率限制後，未找到可公開保證的「註冊送多少」「實名送多少」、通用贈額期限或月度重置規則。

官方[速率限制](https://platform.minimax.cn/docs/guides/rate-limits.md)列 T2A v2：免費用戶 10 RPM、充值用戶 20 RPM。RPM 是每分鐘請求數；它不提供免費字符總量，也不表示免費呼叫可無限持續。

內地付費資源包另有 200 萬字符／1 個月、2,000 萬字符／3 個月、2 億字符／1 年等選項，規則為餘量不繼承、到期清零。這些是購買後的期限及用量，不能當作免費額度或每月自動補發。

## 六、對 BDC 的判斷

- 若只想試聽聲音，可以使用 Audio 網頁 Free 方案；每月約 12 分鐘 HD 比較適合短文及音色體驗。
- 若要每日在 BDC 閱讀文章，暫時不能以「每月有固定免費 API」作選型前提，應以 API 按量價計算預算，再按實際帳戶贈額抵扣。
- 逐句合成及重讀應考慮音訊快取，否則同一段文章重新合成仍會消耗額度。
- 本次沒有驗證 MiniMax 首音訊延遲，也沒有與目前 Kokoro 或舊 TTS 作同條件測試，不能據定價推論速度或音質。
