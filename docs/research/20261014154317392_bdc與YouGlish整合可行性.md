# bdc 與 YouGlish 整合可行性

bdc 可以透過 YouGlish 官方網頁元件加入真實語境聆聽。建議先在單字學習頁試行，再延伸至文章中的詞組。本文屬方案探討；尚未實作或驗證實際網絡播放。

## 學習流程

目前 features/learning/learning.js 的 displayWordDetails 顯示單字、音標、釋義及例句，speakCurrentWord 呼叫 modules/audio.js 朗讀。可在此增加「聽真實用法」入口：選詞 → 開啟影片面板 → 聽兩至三個語境 → 重播跟讀 → 回到現有造句練習。跟讀首先是學生活動，不代表已有錄音或發音評分功能。

第二階段可從文章詞組分析入口搜尋片語，例如 look forward to。整句教材原文未必有搜尋結果，宜讓學生修改查詢或縮短至詞組。

## 接入方式比較

| 方案 | 使用體驗 | 工作量與限制 |
| --- | --- | --- |
| 跳轉 YouGlish 搜尋 | 點擊後在新頁聆聽 | 最低成本，需驗證查詢網址格式；學習過程會離開 bdc |
| 官方 Widget 加 JavaScript API | 在 bdc 面板內播放與切換語境 | 建議的產品形態，需要處理載入、音訊互斥、窄螢幕與失敗狀態 |
| 收藏語境並延伸練習 | 回顧來源及結合 AI 解析 | 後續再評估字幕保存授權、可靠定位與同步資料模型 |

官方 API 支援依單字或詞組及口音查詢，以及重播、上一段、下一段和速度控制。字幕與影片變更事件可提供字幕及影片 ID；這不等同於已具備完整素材下載或可靠時間戳收藏能力。[JavaScript API](https://youglish.com/api/doc/js-api)

## 建議的最小版本

先在單字詳情提供入口，點擊才載入官方腳本，使用一個共用播放器；顯示字幕、口音選擇、重播與下一段。可用 widget.fetch(word, 'english', 'uk') 查詢英式語境。預設不自動播放，空結果允許修改查詢，失敗時保留原有朗讀並提供開啟原站入口。

新增 modules/youglish.js 封裝腳本載入及播放器生命週期，learning 模組傳入當前 word.word；DOM 參照集中於 modules/dom.js，介面文案同時維護 zh-CN 與 zh-HK。播放器開始時停止現有 TTS；啟動 TTS、切詞、關閉面板或離開頁面時暫停影片。第一版不改詞書或同步結構。

## 實際邊界

- YouGlish 使用 YouTube 播放，需在目標家庭、學校和裝置的實際網絡驗證。此能力依賴連線，不能承諾離線使用。
- 官方政策要求面向 13 歲以下兒童的服務開啟 Restricted Mode。限制模式不能替代教材的年齡與難度篩選，建議先用現有詞書抽樣檢查結果。
- 商業用途及行動 App 使用需取得官方明確許可；大量展示可能有附加條款。公開文件不足以確定本專案的費用或配額，不能承諾免費無限使用。
- 需保留 Powered by YouGlish.com 標示、完整可見且至少 200 × 200 的 YouTube 播放器，以及政策要求的服務條款和私隱連結。嵌入不宜設計成隱藏影片的純音訊來源。

以上政策依據：[官方 Widget 與 Developer Policy](https://youglish.com/api/doc/widget)。

## 試行判斷

先用約二十個現有教材單字及詞組測試：實際可播放率、語境是否適齡、學生能否理解、是否願意重播跟讀。若播放穩定且語境有幫助，再加入文章入口。字幕匯入、AI 練習生成與收藏功能應在確認資料使用條件後另行設計。
