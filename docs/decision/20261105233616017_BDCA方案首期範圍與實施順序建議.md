# BDC A 方案首期範圍與實施順序建議

- 日期：2026-11-05（Asia/Hong_Kong）
- 決策問題：完整方案應先做哪一部分，才能盡快試用並降低後續返工。
- 依據：[A 方案完整報告](../report/20261102013247144_BDC跨平台查詞與文章收藏A方案完整報告.md)。
- 文件性質：實施優先次序與首期交付邊界；具體函式、遷移及測試拆分於開始開發時另作實施計劃。

## 1. 建議先做的產品流程

第一個可試用版本先完成桌面的「原網頁查詞 → 選詞書收藏 → 保留原句與文章網址 → 回 BDC 看見結果」。

這條流程同時驗證最核心的閱讀需求、AI 配置復用、永久保存及來源關聯，後續 Android PWA 亦能沿用其查詢與收藏能力。

首期收藏文章的保證是網址、可取得的標題及原句已保存。正式正文導入與英文整理接在後面，不讓全文抓取成功與否影響加詞。

## 2. 第一項技術工作：最小擴充套件驗證獨立 AI

先用一個最小擴充套件頁面，驗證同一個帳戶在沒有 BDC 分頁時能完成一次語境查詞。

需驗證的事實包括：

- 能連結帳戶，取得可使用的任務／供應商配置，正確解析「查詞／單詞分析」的模型。
- 在擴充套件 origin 取得及使用必要憑證，通過後端 Origin 檢查及供應商連線要求。
- 對管理員供應商、已同步個人供應商及僅網站本機 Key，分別確認可用路徑；本機 Key 缺失時提供明確連結／匯入方式。
- BDC 分頁關閉後仍可完成請求，不能以依賴隱藏網站分頁的原型冒充獨立執行。

這個驗證先於完整面板及大範圍 AI 模組拆分。現有程式能在網站執行，不等於另一個 origin 自動擁有相同設定與憑證。

## 3. 第一個可試用版本的範圍

| 項目 | 首期交付 |
| --- | --- |
| 入口 | 桌面 Chrome／Edge，選詞後由右鍵或擴充套件入口開啟 |
| 查詢 | 單詞／短語與可取得的原句及附近短語境，復用對應 AI 任務 |
| 顯示 | 簡短釋義、音標及詞性；結果缺失／失敗有清楚狀態 |
| 詞書 | 預設詞書及改選既有詞書；按頁記住臨時選擇 |
| 保存 | 明確點收藏才永久保存；保存已展示的有效解釋，不重跑同一釋義 |
| 來源 | 原句、URL、可取得的標題、當次意思及收藏時間 |
| 待讀 | 有 URL 時同時建立／沿用待讀記錄；主站有最小列表可回訪 |
| 去重 | 同詞追加來源，同一次請求重送不重複新增 |
| 主站展示 | 詞條可看來源，返回 BDC 後能看到新收藏及待讀網址 |
| 可靠性 | 本機待傳、回應遺失重試、帳戶切換及目標詞書刪除有明確行為 |
| 雙語 | 所有新增界面、動態狀態及錯誤均提供 `zh-CN`／`zh-HK` |

句子解析、自由追問、新建詞書快捷入口等已確認能力，在這個基礎穩定後分批補齊，不改變完整方案範圍。

## 4. 編碼依賴順序

1. **獨立 AI 連線驗證與共用任務邊界。** 先取得擴充套件實際連線證據，確定需抽出的設定／執行環境適配。
2. **來源契約與收藏服務。** 擴充來源欄位，完成任意目標詞書、待讀資源、交易回執與業務去重；永久層與備份同步納入。
3. **BDC 輕量查詢／收藏界面。** 用可直接打開的入口測通選詞、釋義及收藏，主站提供來源與待讀展示。
4. **接上最小擴充套件的網頁取詞和面板。** 沿用相同業務服務，處理當前詞、頁面及帳戶切換。
5. **跑通首期跨環境驗收。** 驗證 BDC 分頁關閉、離線重試、重複來源及兩種語言，再交付試用。

這是依賴順序，不要求先搭完所有通用框架。每一步以支撐同一條可用流程為界，避免先重構完整 AI 系統而遲遲沒有可試用結果。

## 5. 後續產品順序

| 優先次序 | 交付目標 | 原因 |
| --- | --- | --- |
| 1 | 桌面查詞、詞書收藏與待讀來源 | 最快驗證核心需求，建立多端共用能力 |
| 2 | 補句子解析與 AI 追問；接通待讀正文導入 | 復用已驗證的配置與保存模型，完成日常閱讀體驗 |
| 3 | 正文版本、英文整理稿及文章內已收藏詞展示 | 需要已保存正文及可靠來源關聯 |
| 4 | Android 手機查詞頁、PWA 安裝及分享接收 | 共用查詢、AI、詞書與來源能力已穩定，主要增加平台接收與手機驗證 |
| 5 | 原生 Android 選字、其他瀏覽器、正文快照及批量提詞 | 依實際使用情況增加，分別處理平台與內容複雜度 |

手機響應式佈局可在共用界面階段一併考慮；PWA service worker、系統分享及安裝流程在查詢／收藏基礎完成後接入。

## 6. 首期驗收的實際例子

使用者在一篇網頁選取 `charge`：

1. BDC 分頁未開，擴充套件仍顯示這句中的「收費」。
2. 主按鈕顯示預設詞書，亦可改選「工作英語」。
3. 點加入後，詞條、原句及來源網址有永久保存回執，網址進待讀。
4. 回 BDC 可在目標詞書看到該詞，展開來源可回訪原頁。
5. 在另一篇文章遇到同詞不同意思，追加新來源而不覆蓋舊釋義。
6. 斷網收藏及回應遺失重送，恢復連線後不產生重複詞條或待讀記錄。

完成上述例子，才算第一個可試用版本；只有靜態面板、能呼叫 AI 或只寫入相容 localStorage，都不足以代表這條流程已完成。
