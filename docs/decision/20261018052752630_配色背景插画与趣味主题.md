# 配色背景插畫 + 兩套趣味主題（焰橙 / 夜刃）

- 日期：2026-10-18
- 狀態：已實作
- 涉及檔案：`modules/theme-art.js`（新增）、`modules/theme.js`、`modules/settings.js`、`features/sync/sync.js`、`styles.css`、`locales/zh-CN.js`、`locales/zh-HK.js`、`tests/floating-player-and-icons.cjs`

## 背景

使用者想在自用環境（不對外公開）把喜歡的角色圖當作配色背景，並希望有兩套「特別」的配色可以搭配。原本的主題機制只換 CSS 變量（主色階 + 紙面淡色偏），撐不起「角色主題」的識別度。

## 決策

### 1. 背景插畫：運行時自選，圖片只留在本機

不把任何角色圖片打包進專案（避免進版控、進部署包），改為「每套配色各掛一張使用者在設定裡選的本機圖片」：

- 圖片本體：IndexedDB `bdc-theme-art`（version 1，store `arts`，keyPath `themeId`），記錄形如
  `{ themeId, blob, name, type, width, height, updatedAt }`。
- 讀入時用 `createImageBitmap` + canvas 縮到長邊 ≤1920 並轉 WebP（quality 0.82）；任何一步失敗就退回原始檔，保證功能可用。
- 顯示參數：`pen_global_settings.themeArt = { enabled, strength, blur }`，預設 `{ true, 0.22, 2 }`。
- **不進同步**：同步快照只帶 `settings.ai`（見 `modules/sync-core.js`），`themeArt` 天然不會外流。
- 限制：單檔 ≤20 MB；只收 `image/*`。

### 2. 渲染方式

- `html[data-theme-art="on"]` 時才建立兩層 fixed 背景：
  - `body::before`：`--theme-art` 圖片，`center top / cover`，`filter: blur(var(--art-blur))`。
  - `body::after`：`--paper` 遮罩，`opacity: var(--art-scrim)`（= 1 − strength），控制可見度。
- `.app-layout` 建立 `position: relative; z-index: 1` 堆疊上下文，內容永遠在插畫之上。
- 卡片仍是純白 `--surface`，內文、單字列表、例句完全不受插畫影響。
- 插畫開啟時側欄／底部導航改半透明毛玻璃（`rgba(255,255,255,.66)` + `backdrop-filter`），避免插畫在側欄邊緣被切成硬塊。
- 首圖焦點預設 `center top`（人物圖通常主體偏上）。

### 3. 兩套趣味主題

| id | 名稱 | 主色 | 紙面 | 品牌標漸層 |
| --- | --- | --- | --- | --- |
| `flame` | 焰橙 | `#c2410c`（白字 5.18:1） | `#f6f2f1` | `linear-gradient(150deg,#f97316,#b91c1c)` |
| `night` | 夜刃 | `#1f2937`（白字 14.7:1） | `#eceef1`（比其它主題更灰） | `linear-gradient(150deg,#4b5563,#0b1220)` |

主色刻意不用 `#ea580c`（白字僅 3.56:1），改用深一階的 `#c2410c`，按鈕文字才過 AA。

### 4. 沒有開放 `--accent` 覆寫（重要取捨）

`--accent`（`#e08600`）在現有程式碼裡是**警告語義**（`.warning` 按鈕、`.badge-warn`、`.message-warning`、`.validation-warnings`、`.score-poor` 等 17 處），不是裝飾色。若讓主題覆寫它，警告按鈕會變成該主題的顏色，語義會被破壞。

因此改成新增一個純裝飾通道 `--brand-gradient`（只給品牌標用），趣味主題靠它 + 主色 + 自訂插畫表達個性。日後若真需要覆寫警告色，應先把「裝飾強調」與「警告」拆成兩個令牌，再談主題覆寫。

## 驗證

- `node tests/audit-i18n.mjs`：zh-CN / zh-HK 各 1589 鍵，無缺鍵、插值一致。
- 瀏覽器（`python3 scripts/serve.py` 後）：
  - 設定 → 界面 → 配色主題：10 個色塊換行正常，10 套都即時套用並寫入。
  - 背景插畫：`选择图片` 後狀態顯示檔名與尺寸、`移除` 出現；`浓度 / 模糊` 滑桿即時生效並寫入 `themeArt`。
  - 切換到沒有圖的配色 → `html[data-theme-art="off"]`，插畫層消失；切回 → 圖片回來。
  - 重新載入頁面 → 配色（localStorage）與插畫（IndexedDB）都還在。
  - 關掉「顯示背景插畫」→ 立即隱藏，圖片仍保留。
- 已知限制：插畫只作用於主應用，獨立頁 `phonetics.html` 不套用；每套配色一張圖，尚無焦點位置（focal point）調整；快速連續切換配色時用序號丟棄過期的 IndexedDB 回應。

## 素材與版權

本機制只提供「使用者自選本機圖片」的能力，專案內不包含任何角色圖片；圖片不會上傳、不同步、不進版控。素材請自行確認使用權利，本專案不對使用者放入的圖片做任何分發。

## 追加：品牌圖標也跟主題走

左上角品牌標原本固定用 `#ic-app`（紙頁圖標），現在拆成兩層：

1. **內建線性圖標（隨主題）**：`THEMES` 增加可選 `icon` 欄位，`applyTheme()` 會把 `.brand-mark use` 的 `href` 換成該主題圖標（同時寫 `html[data-brand-icon]` 便於除錯）。
   - `flame` → `#ic-flame`（火焰）、`night` → `#ic-blade`（刀），其餘主題沿用 `#ic-app`。
   - 新圖標是 `index.html` 裡 sprite 的兩個 symbol（24 網格、1.7 描邊，與既有線性圖標同規格）。
2. **自訂圖片（每套配色可各一張）**：`bdc-theme-art` 升到 v2，新增 `icons` store（同樣 keyPath `themeId`、只存本機）。
   - 圖片縮到長邊 256 再存；套用時掛在 `.brand-mark-img` 並給 `.brand-mark` 加 `has-custom-icon`，同時隱藏內建線性圖標。
   - 沒設自訂圖片就自動回到該主題的內建圖標；「恢復預設」清掉記錄。

設定面板「界面」分頁新增「品牌圖標」卡片：選擇圖標／恢復預設／目前檔名與尺寸。

**未做**：favicon 仍固定用紙頁輪廓（只換底色）。若要讓分頁圖標也跟著換，需要在 `updateFavicon` 內放一份 glyph path 表（sprite 的 symbol 無法被 data URL 引用），屬於另一件小事。

## 驗證（品牌圖標）

- 逐套切換：`teal/blue/indigo/violet/slate/forest/candy/coffee` → `#ic-app`，`flame` → `#ic-flame`，`night` → `#ic-blade`。
- 上傳自訂圖標後：`.brand-mark` 出現 `has-custom-icon`、`<img>` 顯示 blob URL、內建圖標隱藏、狀態列顯示 `檔名 · 256×256`、「恢復預設」可見。
- 「恢復預設」→ 圖片消失、回到該主題內建圖標。
- `tests/floating-player-and-icons.cjs` 的 `THEME_EXPECT` 已加上圖標欄位並納入斷言。

## 追加：火影主題的內建預設頭像與背景

使用者提供兩張素材，作為「火影」主題（id 仍為 `flame`，顯示名稱由「焰橙」改為「火影」）的**預設**頭像與背景。

### 素材落盤

| 用途 | 檔案 | 尺寸 | 體積 |
| --- | --- | --- | --- |
| 品牌頭像 | `assets/theme/flame-icon.webp` | 256×256 | 26 KB |
| 背景插畫 | `assets/theme/flame-bg.webp` | 1086×1448 | 134 KB |

由原始 PNG 用 `magick` 轉 WebP（頭像 q88、背景 q82）並去除 metadata 產生。

### 優先序（`modules/theme-art.js`）

- 背景：使用者自選圖（IndexedDB）→ 內建預設圖（`assets/theme/*`）→ 無（關閉插畫層）
- 品牌圖標：使用者自選圖（IndexedDB）→ 內建預設圖（`assets/theme/*`）→ 主題線性圖標（`#ic-flame` 等）

`THEME_DEFAULTS` 目前只有 `flame` 一項；新增主題預設圖只要往這個對照表加一筆，不必動 UI。

### UI 連動

- 背景狀態列在沒有自選圖但有內建圖時顯示「使用主題自帶圖片」，且「移除」按鈕隱藏（本來就沒東西可移除）。
- 「顯示背景插畫」開關在有內建圖時也保持可用，關掉會把內建圖一起藏起來。
- 品牌頭像改成 `object-fit: cover`（26 px 填滿 34 px 品牌標，留 4 px 漸層邊），比縮小放置更好辨識。

### 注意

素材為角色插畫，僅供本機自用；若日後要公開部署，請先把 `assets/theme/` 換成自有或授權素材，或把該目錄排除在部署之外（否則會隨靜態資源一起發布）。

### 驗證

- 乾淨來源（新 port、IndexedDB 為空）切到「火影」：`--theme-art: url("assets/theme/flame-bg.webp")`、左上角顯示 `flame-icon.webp`、內建線性圖標自動隱藏。
- 關掉「顯示背景插畫」→ `data-theme-art="off"`；再打開 → 回來。
- 切到「墨青」→ 插畫關閉、頭像圖隱藏、圖標回到 `#ic-app`。
