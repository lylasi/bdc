# 配色主題擴充（4 套新增）

- 日期：2026-10-18
- 狀態：已實作
- 涉及檔案：`modules/theme.js`、`styles.css`、`locales/zh-CN.js`、`locales/zh-HK.js`、`tests/floating-player-and-icons.cjs`

## 背景

原本只有 4 套配色（墨青／靛藍／紫羅蘭／石墨），全部落在「冷色 + 低彩度」區間，
缺少明確的品牌藍、兒童向的活潑色，以及暖色系選擇。需求為：新增 1 套主題藍、
1 套適合小學生的顏色、再新增 2 套與現有色系差異較大的配色。

## 決策

| id | 名稱（zh-CN／zh-HK） | 主色 | 理由 |
| --- | --- | --- | --- |
| `blue` | 海藍 / 海藍 | `#2563eb` | 標準品牌藍，與靛藍（`#4f46e5`，偏紫）在色相上可明確區分；白字對比 5.17:1 |
| `candy` | 糖果粉 / 糖果粉 | `#db2777` | 高彩度暖粉，活潑、明亮，適合小學生；實際套用於按鈕、標籤時仍維持 AA（白字 4.60:1） |
| `forest` | 森林綠 / 森林綠 | `#15803d` | 自然、成長意象，色相（約 142°）明顯偏離墨青（約 175°）與其他冷色 |
| `coffee` | 咖啡棕 / 咖啡棕 | `#8a5a2b` | 暖色大地系，與既有全部冷色系距離最大，且貼合「溫潤紙感」的整體設計基調 |

未採用橙／琥珀系作新主色，因其與既有語義色 `--accent`（`#e08600`）過近，會削弱強調色的辨識度。

排列順序：先沉穩冷色（墨青、海藍、靛藍、紫羅蘭、石墨），再活潑與自然色系（森林綠、糖果粉、咖啡棕）。

## 順帶修正

1. `--ring` 改由 `--primary-rgb` 推導，不再於每個主題重複寫死 `rgba()`。
2. 三處寫死墨青色的陰影（品牌標、聽寫主按鈕、QA 題號徽章）改用 `rgba(var(--primary-rgb), α)`，避免在藍／粉／綠／棕主題下殘留青色陰影。
3. 補上原本被引用但未定義的 `--primary-500`（AI 模型選項的邊框與焦點環），並為每套主題提供對應色階。

## 約束

- 只切換主色階（`--primary` 系列與焦點環），語義色（`--ok`／`--danger`／`--accent`／`--info`）不變。
- 每套主題皆需滿足：白字壓在主色上 ≥ 4.5:1、`--primary-600` 文字壓在紙底／白卡上 ≥ 4.5:1。
- 新增主題需同步：`modules/theme.js` 的 `THEMES`、`styles.css` 的 `:root[data-theme=…]` 區塊、兩份 locale 的 `settings.theme*` 文案，以及 `tests/floating-player-and-icons.cjs` 的 `THEME_EXPECT`。

## 驗證

- `node tests/audit-i18n.mjs`：zh-CN 與 zh-HK 鍵數一致（1560 / 1560），無缺鍵。
- 以腳本計算 8 套主題的對比度，全部通過 AA。
- 尚未執行瀏覽器巡檢（本機無 Playwright 模組），建議 `python3 scripts/serve.py` 後開設定彈窗確認 8 個色塊換行與即時套用。

## 追加決策（同日）：紙面帶極淡主色

原本主題只換強調色，頁面底色在 8 套主題下完全一致，視覺差異偏小。經確認採用「紙面與卡片帶極淡主色」方案：

- 做法：保持亮度不變，只把色相換成主題主色的色相、彩度壓到 16–22%，逐主題寫死 hex（不用 `color-mix`，避免舊瀏覽器不支援導致宣告失效）。
- 受影響令牌：`--paper`、`--paper-2`、`--surface-2`、`--surface-3`、`--line`、`--line-strong`。
- `--surface` 維持純白：卡片保持乾淨，淡色紙面在卡片周圍形成層次。
- 文字墨色、語義色、圓角、陰影、間距一律不動；文字對比度與改動前差異在 0.05 以內。
- 各主題紙面（paper）：墨青 `#f1f6f6`、海藍 `#f1f3f6`、靛藍 `#f1f1f6`、紫羅蘭 `#f3f1f6`、石墨 `#f1f3f6`、森林綠 `#f1f6f3`、糖果粉 `#f6f1f3`、咖啡棕 `#f6f3f1`。

副作用與已知取捨：

- 預設墨青的紙面從暖米白（`#f5f4f1`）變成極淡冷綠（`#f1f6f6`），原本「溫潤紙感」的暖度降低；若日後想保留預設暖底，只改 `:root` 的紙面值即可，其餘主題不受影響。
- 海藍與石墨的紙面數值相同（色相 221° / 215° 在極低彩度下難以區分），兩者靠主色與強調色區分。

同步更新：`settings.themeHint` 兩份語言的文案改為「主色與紙面底色會一起更換，文字、提示色與排版保持不變」，`tests/floating-player-and-icons.cjs` 的 `THEME_EXPECT` 增加紙面底色並納入斷言。

## 追加決策（同日，第二次調整）

1. **墨青保留原本的暖白紙面**：`:root` 的 `--paper` 系列還原成 `#f5f4f1 / #efede8 / #f3f2ee / #e7e4de / #d5d1c9`，不再跟隨主色做色偏。理由是「溫潤紙感」是預設主題的設計基準，其他七套才帶極淡主色偏。
2. **海藍調深**：主色 `#2563eb` → `#1d4ed8`（色階 `500 #2563eb`、`600 #1e40af`、`700 #1e3a8a`），紙面同步微調為 `#f1f2f6`。原因：原本的藍偏亮、按鈕面積大時略刺眼；調深後白字對比從 5.17:1 提升到 6.70:1，仍與靛藍（偏紫）區分明顯。

調整後的紙面：墨青 `#f5f4f1`（暖白）、海藍 `#f1f2f6`、靛藍 `#f1f1f6`、紫羅蘭 `#f3f1f6`、石墨 `#f1f3f6`、森林綠 `#f1f6f3`、糖果粉 `#f6f1f3`、咖啡棕 `#f6f3f1`。
