## 獨立審查與修正

DSH 首輪獨立審查判定可發布，另指出中文原文無效入口、自動捲動關閉選單、Tab 焦點及香港用詞。四項已修正，並由 DSH 在乾淨發布副本複查通過：獨立斷言 106 + 16 + 7 = **129 項零失敗**，產品測試十組全數通過。

中文原文段落會停用英文朗讀並顯示原因；錨點仍可見時選單跟隨捲動；Tab／Shift+Tab 沿正文控制順序導航；香港繁體用「朗讀選取內容」。跨模組背景播放保留既有策略，浮動停止控制可用。非阻擋的無障礙結構及既有術語觀察保留於 DSH 報告，沒有擴大修改範圍。

發布準備期間遠端已更新至 `d259c2d`，故以 fast-forward 相容方式 rebase，保留對方更新，只解決生成 import map 與同時新增字典鍵的衝突。句尾操作模組與 DSH 複查版本相同；整合後再執行其獨立測試及產品回歸。
