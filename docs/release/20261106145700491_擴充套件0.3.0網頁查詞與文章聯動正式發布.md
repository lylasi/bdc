# 擴充套件 0.3.0 網頁查詞與文章聯動正式發布

發布日期：2026-11-06（Asia/Shanghai）。依使用者「測試沒問題就可以更新」的既有授權，完成原網頁查詞、直接建立詞書、AI 擷取文章及同頁關聯，並更新原 Worker、Git remote 及 149 主站。

## 已發布功能

- 普通 HTTP／HTTPS 網頁選取單詞或短語後，在原頁浮窗顯示語境查詞結果並收藏，不必切換工具列面板。帳戶和 AI 設定沿用現有服務。
- 浮窗可直接建立本頁詞書、自訂詞書或預設生詞本；明確設定預設後按帳戶保存，同頁已選詞書優先沿用。
- AI 提取目前網頁的標題、正文及 Markdown 章節，先預覽及修改，再保存至文章詳解；可選擇保存前逐段 AI 分析，或稍後在主站分析。
- 本頁詞書先建立或文章先匯入，兩種順序均能自動補上關聯；主站沿用已關聯的頁書，不另建空白詞書。
- 同一網址已有文章時提供原記錄開啟入口，保留已編輯內容；保存回應遺失時沿用原待傳，重開後還原並鎖定原稿，提供重試及取消。
- 收藏使用已展示的意思，收藏及重送不重跑 AI。所有新增操作、載入及錯誤文案均提供 zh-CN／zh-HK。

## 使用及更新

在另一部電腦的專案 master 執行：

```bash
git pull --ff-only origin master
node scripts/package-extension.mjs
```

在 chrome://extensions／edge://extensions 重新載入 extension/，確認 0.3.0，將原本已開啟的網頁重新整理一次。之後選詞 → 按浮動查詞按鈕 → 選書或直接建立本頁詞書 → 加入詞書。整篇文章則按「AI 擷取本頁文章」，檢查預覽再保存。

[完整操作說明](../spec/20261106141147557_網頁查詞與詞書文章聯動操作說明.md)。[0.3.0 ZIP](../report/assets/20261106140441286_page-validation/BDC-extension-0.3.0.zip)，SHA256 `32a285852ff8af5341ffac25d0f7b7e0bb784b975c2b1007e75a1904087b89f8`；打包內的配置已確認等於公開範例，沒有私有 AI Key。

## 尚存限制

受保護的瀏覽器內建頁不能注入，仍可從工具列手動查詞；同網址已有文章時沿用現有記錄，後續修改在主站完成。正文抽取使用可讀區域及 AI 清理，需使用者預覽，空結果、截斷或超限均會提示。

DeepSeek 記錄的非阻擋觀察仍保留：兩個面板同時編輯同頁時，另一份待傳可能取代尚未保存的預覽；關聯回執只驗身份格式，未再與先前讀到的 ID 比較；登出後本機待傳暫不提供清除入口。另有既有其他 Worker 路由未 await 的 DB 故障封套問題，非本分支回歸，詳見獨立報告。未以真實用戶資料、長篇網站全集或實際 PostgreSQL 測試。

如需回退，應協調 Worker 和主站版本，以 Git revert／既有發布流程處理，保留新增偏好表及既有收藏回執表，避免刪除已保存資料。
