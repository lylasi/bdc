  - 若日後想固定公開連結，把註解裡的 `publicBaseUrl: 'https://bdc.a4a4.qzz.io',` 取消註解即可（需含 scheme）。
- `SYNC.publicBaseUrl` 的作用與影響（本檔案已用註解標明，值維持不設定）：

| 設定 | 產生出來的登入連結／QR | 適用情況 |
| --- | --- | --- |
| 留空（目前） | 跟隨**管理員當下開啟面板的網址**（去 `#`、去 `?query` 後接 `#login=<碼>`）。從 `https://bdc.a4a4.qzz.io` 開 → 公開連結；從 `http://10.10.10.149:8000` 開 → 同網段連結 | 多入口並存、想「用哪個入口產生就用哪個入口收」 |
| `'https://bdc.a4a4.qzz.io'` | 不論從哪開面板，一律產生 `https://bdc.a4a4.qzz.io/#login=<碼>` | 固定對外網址，避免管理員用內網 IP 開面板時產生只能在家的連結 |

注意：值必須含 scheme（`https://` / `http://`）且能開啟本 SPA；只寫 `10.10.10.149:8000` 會被
`new URL()` 當成自訂 scheme 而產生壞連結。此設定只影響「產生出來的連結／QR」，不影響登入驗證、
API 呼叫或 CORS（那些仍由 `SYNC.endpoint` 決定）。
