## 現在如何使用及維護

1. 開啟原網站，重新載入頁面；已開啟很久的分頁可強制重新整理。
2. 使用 `lylasi` 原有通行碼登入。若剛提升角色而介面未出現管理入口，登出再登入。
3. 右上角設定 → 全局設定 → AI 設定中的「管理預設供應商」。
4. 在管理面板新增供應商時輸入 URL、Key，連線取得模型；勾選可提供給使用者的模型，設定任務映射。
5. 修改完成按「發布變更」。後續清單與 Key 維護透過此面板完成，毋須編輯 `ai-config.js` 或重新部署 Worker。
6. 「歷史版本」可查看發布紀錄及還原版本；還原前確認舊供應商與 Key 仍有效。
7. 個人供應商入口仍在全局設定中，普通用戶也可新增自己的 URL、Key。

舊短通行碼仍可同步學習資料，但 AI 雲端接口要求至少 32 個字元。若介面提示通行碼強度不足，請在帳戶設定使用「更改通行碼」，可用「產生隨機通行碼」並保存新值；其他裝置需改用新值登入。部署沒有替任何真實使用者更改通行碼。

## 已知邊界

這次實作讓登入用戶取得憑證後由瀏覽器直連 AI 供應商，Worker 負責帳戶、列表及加密儲存，並非代轉所有 AI 請求。因此登入用戶仍能從自己的請求中讀到共用 Key；不能把此方案視為對登入用戶隱藏供應商密鑰的代理服務。

原公開設定中的 HAPI Key 沿用至加密列表，並未在上游撤銷換新；移除靜態設定不能撤回舊副本。當前前端 CDN 回應有 4 小時快取，已驗證此次所在節點的九個檔案均為新版，但未清除全球所有節點快取。需要撤銷曾公開 Key 時，在供應商端輪換後透過管理面板發布新 Key。
