# BDC 擴充套件 0.6.1

詞卡底部現只保留一行「加入詞書」與詞書圖示。

1. 有本頁詞書時直接加入本頁詞書；否則加入「網頁」。若還沒有「網頁」，第一次收藏時自動建立。
2. 點詞書圖示即可選擇另一詞書、建立本頁或自訂詞書，以及直接查看詞書。手動改選用於當前面板；新開詞卡再次按本頁優先規則選擇。
3. 既有「網頁生詞」會沿用；文章原文、原句及定位繼續隨詞條保存。簡繁體與窄窗口已驗證。

[下載安裝包](assets/20261107004241183/BDC-extension-0.6.1.zip)；[驗證記錄](../report/20261107004241183_擴充單行收藏列與自動詞書驗證.md)。

用包內 extension/ 更新原安裝目錄，在擴充管理頁按重新載入，再刷新閱讀網頁。若直接載入工作區 extension/，重新載入即可生效。
