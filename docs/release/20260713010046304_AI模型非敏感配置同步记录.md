# AI 模型非敏感配置同步记录

## 变更内容

- 在同步快照中新增独立的 `aiSettings` 分组，并使用分组级 `updatedAt` 做最后写入优先合并。
- 同步 AI Provider 的名称、启用状态、Base URL、API URL、Models URL、允许模型、已抓取模型摘要和抓取状态。
- 同步各 AI 任务的模型映射。
- 保存 AI 设置后发送 `aiSettings` 数据变更信号，沿用现有自动同步调度。
- 新浏览器拉取快照后，将较新的 AI 设置恢复到 `pen_global_settings`。

## 隐私边界

- 不同步 `pen_global_secrets`。
- 不同步 Provider `apiKey`。
- 已抓取模型只同步展示及选择所需的摘要字段，不同步接口响应的 `raw` 原始对象。

## 兼容性

- 旧快照没有 `aiSettings` 时保持原行为，不影响其他数据分组。
- 旧版已保存的 AI 设置可使用 `pen_global_settings.updatedAt` 作为首次迁移时间戳。
- 仅修改语言、阅读或其他非 AI 设置的旧浏览器不会以空 AI 配置覆盖云端模型配置。

## 验证结果

- `node --check modules/settings.js`：通过。
- `node --check modules/sync-core.js`：通过。
- `git diff --check`：通过。
- 使用模拟两个浏览器时间戳的快照验证：远端较新模型映射可正确覆盖本地。
- 快照序列化检查：不包含 `apiKey`、测试密钥或已抓取模型的 `raw` 字段。
- 远端设置应用后，`pen_global_secrets` 保持不变。

## 手动验收建议

1. 浏览器 A 登录后配置 Provider、抓取并勾选模型、设置任务映射，然后点击“保存”。
2. 执行同步，或等待自动同步完成。
3. 浏览器 B 使用同一账号登录并同步。
4. 重新打开全局设置，确认地址、允许模型、抓取清单和任务映射已恢复。
5. 在浏览器 B 检查 API Key 仍为空，需要本机单独填写。
