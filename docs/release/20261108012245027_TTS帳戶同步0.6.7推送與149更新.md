## 核對與使用

唯讀正式 D1 統計確認舊快照沒有 TTS 群組；首次遷移會在使用者刷新已登入主站時進行。需要更新並重新載入本機擴充，再重新整理閱讀頁。

入口：瀏覽器工具列的 BDC 擴充 → 右上雙滑杆 → 介面語言下方「語音 / TTS」。詞卡亦可點鉛筆右邊、× 左邊的雙滑杆，或聲音來源文字。主站則是全局設定 → 語音朗讀，等待「已儲存到目前帳戶」。
