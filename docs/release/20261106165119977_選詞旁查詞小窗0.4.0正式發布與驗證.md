## 使用行為

- 選取單詞或短語，再點「查詞」才發出查詢；結果小窗約 340px 寬，貼近選詞，依空間翻到上方或左右避讓，高度隨內容調整。
- 頁面及容器捲動時跟隨選詞，選詞離開可視範圍便收起；點外面或 Esc 收起普通小窗。每頁只有一個小窗，新詞需再明確點「查詞」。
- 小窗預設顯示字詞、音標、詞性、句中釋義及收藏。有效的同頁選擇、本頁詞書、明確預設依次沿用，亦可切換。
- 沒有可用詞書時，一鍵建立本頁詞書並加入目前展示的釋義。先取得建書回執再收藏，收藏不重跑 AI；失敗仍沿用既有待傳及冪等協議。
- 「更多」展開同一 iframe 的完整面板，保留查詞、詞書及文章狀態；編輯時保持固定，明確關閉或返回前保護未保存內容，保存後可返回小窗。
- 文章擷取、章節保留、逐段分析及同頁詞書自動關聯沿用原流程。新增文案完整支援 zh-CN／zh-HK。

帳戶、AI Key 及寫入均留在可信擴充套件頁面。尺寸／模式／關閉改用驗證 sender、documentId、ticket 的擴充套件內部訊息中繼，普通網頁收不到產品的 window message 及票據。保留一次性票據、帳戶隔離、共用 AI 及收藏入口。
