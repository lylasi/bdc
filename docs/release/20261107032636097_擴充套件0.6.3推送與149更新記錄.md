主站 release import map：`3b3a865a186c`，101 個模組；簡繁字典各 2475 鍵，無單邊鍵或插值不一致。全庫 i18n 掃描仍有既有 `phonetics.` 動態鍵及硬編碼候選提示，沒有宣稱全庫零提示。
