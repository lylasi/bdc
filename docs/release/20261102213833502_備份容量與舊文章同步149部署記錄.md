## 驗收範圍

正式前端的唯讀驗證入口為 <http://10.10.10.149:8001> 與 <https://bdc.a4a4.qzz.io>；瀏覽器以隔離 context 和合成設定／mock 帳戶運行。真實同步資料讀寫測試使用本機臨時 SQLite，未對正式使用者資料寫入測試內容。

使用者原網域 bdc.eigui.cn 在本環境先遇到 TLS 憑證問題，略過驗證後仍回 403，因此不能宣稱已直接巡檢該網域或微信真機。該 Origin 對同步 Worker 的 CORS 預檢已驗證通過。實際手機仍須關閉並重開原網站後按「立即同步」確認；應保留原網站資料，避免遺失尚未同步的筆記。快照 v280 是帳戶資料版本，不代表前端發布版本。
