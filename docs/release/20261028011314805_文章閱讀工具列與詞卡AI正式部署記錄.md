# 文章閱讀工具列與詞卡 AI 正式部署記錄

日期：2026-10-28（Asia/Shanghai）。使用者明確要求提交目前修改並更新 149 正式環境，本次已完成提交、推送、部署及驗證。

## 發佈內容

- 文章側欄可收合，正文擴闊；頂部懸浮列集中輸入、匯入、文章庫、閱讀記錄及精簡播放控制。
- 移除工具列重複標題，側欄切換使用圖示；倍速按鈕展開直向滑軌，修正點擊及拖動時誤收合。
- 段落重新獲取收為原文區圖示，移除完成段落底欄；單詞詳解保留重新獲取。
- 詞卡採單行發音、加詞本、標記、AI 及更多圖示，筆記與選短語收進點擊選單。
- AI 在詞卡下方直接提問，支援草稿、歷史、連續提問、停止、重試及放大視窗；保留簡體中文與香港繁體中文。
