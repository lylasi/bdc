## 6. 上線後驗證建議

1. 管理員登入 BDC → 設定 → 工具 → 管理用戶。
2. 對非管理員用戶按「產生配對碼」，確認顯示 12 字元配對碼與 10 分鐘有效期。
3. 在另一台未登入裝置開啟新版前端，登入彈窗選「使用裝置配對碼」，輸入
   「用戶代號 + 配對碼」，確認成功登入且能看到原本的學習資料。
4. 確認原裝置仍保持登入；再重設該用戶通行碼，確認已配對裝置立即失效。
