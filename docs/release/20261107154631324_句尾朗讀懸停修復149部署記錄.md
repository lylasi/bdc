## 修正行為

長英文句子換行、句尾靠左時，朗讀喇叭現在位於「句子解析」浮層標題旁。句尾、浮層與按鈕共用懸停生命週期，鼠標移入提示文字或喇叭時保持顯示，離開整組後延遲收起；支援鍵盤焦點與 Escape。

正文沒有新增常駐喇叭；手機繼續使用句尾「⋯」開啟原有三種朗讀操作。
