# 拆音模块接入验收

## 使用

在 BDC 设置开启「启用拆音练习」（默认关闭，仅本机保存），进入学习模式并选择单词，点击「拆音练习」。弹窗可关闭并回到背词，也可独立打开当前练习。关闭、Escape、切换词条会卸载练习页面并停止音频。

同站点 `phonetics.html` 是独立单词练习入口；`phonetic-chart/index.html` 保留完整音标表、动作图和原有本地录音。设置中的独立入口不受开关限制。

## 部署与边界

新增资源与 BDC 一起作为静态文件部署，不需要额外 Python 服务。原独立 phonetic-chart 项目保留；BDC 中的 `phonetic-chart/` 是公开运行资源快照，不包含 `.tts-local.json`、服务器或密钥。

完整音标表沿用原教学资料；新的 BDC 设置、弹窗和单词练习界面具有简体及香港繁体文案。

更新原图表资源：`python3 scripts/update-phonetic-assets.py /path/to/phonetic-chart`。更新后应重跑检查；不要直接复制整个目录或私有配置。

## 语音

单词发音直接调用 `modules/audio.js` 的 `buildTTSUrl()`，复用 BDC 当前远程／本地／自定义渠道、TTS Key 与对应英美音源。未指定音源时分别用 Abbi / Jenny，不把英音回退成美音。设置读取发生在点击播放时。密钥不写入弹窗地址或分享链接；TTS 请求仍沿用 BDC 既有的 URL 鉴权协议。

HTTPS 网页选择 HTTP 局域网语音时明确提示换 HTTPS 渠道或从本地 HTTP 站点打开，不能规避浏览器混合内容限制。网络渠道不会静默自动切换。

## 音标与查询

优先采用明确口音的传入音标及本地 70 词示例。词条原音标未注明口音时也立即拆音，明确标注口音未确认；不根据用户选的声音强行贴口音标签，也不为了确认口音阻塞练习。

需要查询时通过 `modules/api.js` 新增的 `getWordPronunciations()`，复用既有 wordAnalysis 任务的模型、提供方和鉴权设置。请求明确英美口音，支持最多六种常见读法；按词、口音、语言、提示词版本及模型缓存一天。校验返回词、口音和音标格式，拒绝错误字符串及错误口音，失败不缓存。AI 结果始终标为参考，不能认为已人工核对。

多读音词由用户选读法；单词 TTS 接口仍不能保证朗读与选定 IPA 一致。逐音跟读仅播放独立音，不把 TTS 作为已核对的整词录音拼入流程。未知音素保留且提示缺独立录音。查询失败仍保留单词发音入口。

当前仅支持单个英文单词；短语不拆音。没有恢复 Free Dictionary API 上游，此集成入口不再依赖该故障服务。

开关不进入云同步快照；已经检查设置合并和 sync-core 的 AI 设置同步，不会覆盖此本机偏好。学习页同时修正了选词本与 activeBookId 不一致时详情取错词的问题。

## 验证

- `node --test tests/phonetics.test.mjs`：6 项通过，覆盖默认开关、设置合并、英美音源、实际 URL 构造、未知口音、AI 结构校验及双语键一致性。
- 浏览器：独立临时 Chrome，无用户资料；模拟 AI / TTS 响应，外部请求阻断。简体、香港繁体两轮均通过，无未捕获页面异常。
- 浏览器覆盖默认隐藏入口、保存开关、弹窗打开关闭、未知口音原文、本地命中不请求 AI、缺音标查询、多读音选择、查询失败仍可试听、远程／本地路由、英美声音、关闭开关后独立页可用，以及完整图表加载。
- 390px 手机页面无横向溢出；桌面弹窗与手机截图已检查。
- `git diff --check` 通过。测试没有验证真实 AI 音标的语言学准确性，也没有验证远程 CF 服务当前可用性。

浏览器复跑：启动 BDC 静态服务器后，设置 `PHONETICS_BASE_URL`（默认 http://127.0.0.1:8876），并在需要时设置 `PLAYWRIGHT_MODULE` 为现有 Playwright 模块路径，再运行 `node tests/phonetics.browser.cjs`。测试使用示例配置及临时数据，不读取真实 API 配置和用户浏览器存储。

## shelter 修复补记

用户实测发现原有音标因缺少口音字段被阻塞，又依赖失败的 AI 查询。现改为直接拆词条原音标，无需联网；未知口音仍明确标注。原音标随 URL、刷新、重新查询及试听口音切换保留。括号内的可选音单独显示，不加入逐音跟读。shelter 的 /ˈʃeltə(r)/ 拆成 ʃ、e、l、t、ə，以及可单独试听的 (r)。

新增 shelter 回归：7 项 Node 测试通过，简体及香港繁体浏览器均确认不发起 AI 请求、正确拆解、可点音试听，刷新及切口音不丢音标。查询失败的提示另区分超时、鉴权、网络及无有效音标；本次未确认用户原 AI 请求的具体上游失败原因。
