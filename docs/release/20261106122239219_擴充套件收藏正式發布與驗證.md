## 使用方式

1. 在 `chrome://extensions` 或 `edge://extensions` 重新載入已安裝的未封裝擴充套件，確認版本 **0.2.0**。原工作樹的 `extension/` 可繼續使用；本機原專案 `/Users/linus/CODE/bdc/extension` 亦已生成完整依賴。
2. 使用與 BDC 相同的帳戶，先在主站同步目標詞書。
3. 在英文網頁選字，擷取選詞並語境查詞，明確選擇目標詞書，按「加入詞書」。
4. 返回 BDC 後等待自動同步或按立即同步，在詞條展開「來源」查看原句與原網址。
