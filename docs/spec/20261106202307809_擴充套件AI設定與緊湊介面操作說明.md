# 擴充套件 0.5.0：AI 設定與緊湊介面

## 使用

1. 更新專案後執行 `node scripts/package-extension.mjs`，在瀏覽器擴充功能管理頁重新載入 extension/，確認 0.5.0；已開啟的文章重新整理一次。
2. 初次使用在帳戶設定連接原同步服務及帳戶。連接完成後帳戶表單會收起，帳戶狀態及錯誤仍可查看；點帳戶標題即可重新展開。
3. 在網頁選詞並點「查詞」，小窗貼近選區。展開小窗的「AI 設定」即可選擇帳戶允許的模型及思考模式，毋須回到主站設定。
4. 用途預設為目前查詞，會依單詞、短語或沒有原句的獨立查詞自動對應既有任務；每類查詞各自保留選擇。另外可切至文章擷取、文章翻譯，分別選模型及思考模式。
5. 更改即時保存，下一次請求生效。需要重新查詢眼前的單詞時，點「用此設定重新查詞」。普通選項切換不會自動呼叫 AI，也不會改寫已展示及準備收藏的釋義。
6. 點「恢復帳戶設定」即可刪除這個用途的擴充套件選擇，重新使用帳戶的任務設定及既有預設。

## 模型與思考程度

模型清單沿用帳戶個人供應商和管理員共享目錄的允許模型，不允許透過選項繞過供應商邊界或借用另一家 Key。選定模型失效時保留失效選項並報錯，可更新帳戶資料、選另一模型或恢復帳戶設定。

思考模式包括跟隨服務端、關閉、低、中、高。實際支援依供應商及模型；沿用共用協議適配、思考預算及不支援參數時的既有回退行為。AI 回覆仍受當前介面語言控制，原文及歷史結果不轉換語言。

## 儲存與同步邊界

偏好鍵前綴為 `bdc_extension_ai_preferences_v1:`，後綴為 JSON 格式的 `[endpoint, userId]`。只存任務名、模型識別及思考檔位，不存 Token、Key、provider URL 或文章正文。擴充套件來源的 localStorage 與一般網頁隔離。

偏好是本擴充套件的帳戶選擇，重新開窗、重整頁面或讀取帳戶設定不會覆蓋；其他擴充套件頁面透過 storage 事件更新。未登入時不載入任何帳戶的偏好；換帳戶或換端點讀取自己的分區。登出清理沿用原 AI profile／憑證流程，非秘密偏好按帳戶保留，以便再次登入時恢復。

不寫入主站 AI profile、不回傳 snapshot，不改主站的任務選擇。收藏仍保存當次展示的意思；模型／思考變更不修改收藏回執與待傳項。既有同頁詞書及文章關聯繼續沿用原 Worker API，本輪沒有新增服務、資料表或 migration。
