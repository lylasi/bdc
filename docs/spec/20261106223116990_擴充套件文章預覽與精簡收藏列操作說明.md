# 擴充套件 0.5.1：文章預覽與精簡收藏列

## 查詞及收藏

- 小窗下方是一行「詞書選單、加入、⋯」。選好詞書後點「加入」，保存的是當前展示的意思及原文來源；成功時按鈕改為「已加入」。
- 「⋯」提供新增詞書、本頁詞書、建立／設定預設詞書、刷新詞書和來源連結，按需展開。
- 沒有目標詞書時仍可直接「新增並加入」，建立本頁詞書後收藏，不重跑 AI。
- 錯誤及待傳狀態直接顯示。空書單和一般成功不再重複堆疊提示行。
- 「更多」展開完整面板，編輯選詞、帳戶設定在完整面板工具列；面板依內容調整高度，長預覽保留窗內捲動及未保存草稿保護。

## 擷取文章

在完整面板的「文章」列點「擷取文章」，先檢視及編輯標題、正文和章節，再保存到文章詳解。可勾選保存時逐段分析。

若檢查雲端已有文章的請求遇到網路、逾時或非認證服務錯誤，可先取得 AI 預覽；提示會說明尚未確認雲端舊文章。保存仍需真正的同步回執，會再檢查既有文章並關聯本頁詞書。保存失敗會保留待傳及鎖定原稿，恢復連線後重試，不重跑已完成的 AI。

預查期間可按「停止」；401、權限拒絕、登出或帳戶切換會中止操作，不會使用舊帳戶資料繼續呼叫 AI。已有文章時會提供開啟入口，保留原紀錄。

本次已修復「單一預查失敗便阻塞全部擷取」的客戶端行為。截圖沒有提供請求的實際錯誤碼，無法單憑該畫面判定當次斷線由瀏覽器、網路或服務端哪一層觸發。
