# 完整文章閱讀版匯出規格

日期：2026-10-28。使用者要求移除指定帳戶分享，改為將原文、生詞標記、閱讀記錄、筆記、錄音、短語與 AI 對話整理成可交給別人閱讀的版本。

## 交付範圍

- 主要匯出為單一 HTML，可離線獨立開啟，包含原文、學習記錄、個人及全篇筆記、已儲存 AI 文件與本文對話。Markdown 保留為其他格式；目前帳戶 JSON 備份為獨立選項。
- 原文維持原始文字，文字中的安全標記連到對應學習記錄。重複出現及重疊詞組各自保留關聯，不能僅以文字去重。
- 僅當 contentVersion 相符、positionUncertain 為 false、整數起訖有效、長度符合且原文 slice 完全等於 quote 時放回原文。其他記錄保留於位置待確認清單，不重新猜測位置。
- 記錄包含解釋、翻譯、用法、個人筆記、生字簿關聯、首次及最後查閱時間、標記狀態。可用時顯示文章最後開啟時間，不推斷完成度或閱讀時間線。
- AI 文件的來源可導向已匯出的記錄或訊息；不存在的來源明確提示。對話依建立時間及 ID 排序，保留取消回覆標示與空會話說明。
- 目前沒有個人錄音持久化。HTML 匯出可選擇本機音訊檔，將檔案內容內嵌，提供離線播放器。最多 5 個檔案、原始總大小 25 MiB；格式支援 MP3、M4A、WAV、OGG、WebM、FLAC、AAC、MP4。失敗時停止整次匯出並提供重試。
- 不嵌入 TTS URL、API Key、帳戶 token、供應商設定或完整帳戶資料。筆記／AI 的 Markdown 原始 HTML 必須跳脫；外部圖片改為文字說明，不自動發出網路請求。允許使用者主動開啟安全的 HTTP(S)／mailto／tel 連結。

## 資料一致性及失敗行為

- 從 exportArticleReading(articleId, ctx) 固定本機持久資料快照，明確限制單一文章及其會話／詞彙關聯。
- IndexedDB 和 localStorage fallback 都必須遵守文章及帳戶隔離；讀取失敗回報錯誤，不能當作空資料成功。
- 匯出前保存所有面板及片語筆記草稿；任一保存失敗就停止。
- 每段非同步處理後檢查原始閱讀／文章上下文與目前文章；帳戶、端點、世代或文章切換後不得下載舊工作。
- HTML 不要求先同步。文件標示本機匯出範圍，保留待同步、讀取錯誤、衝突及位置待確認提示；不宣稱包含其他裝置或尚未持久化的串流回覆。
- zh-CN 與 zh-HK 使用同一套功能；所有介面及產物標籤使用字典，原文、筆記、錄音名稱及歷史對話不轉換。

## 驗收

經實際應用入口匯出並捕捉下載；獨立開啟 HTML，在桌面和手機寬度驗證標記、關聯連結、內容、安全跳脫、內嵌音訊及沒有外部資源依賴。兩個 locale 驗證選擇、取消、成功、失敗及重試。保留 Markdown、JSON、草稿保存及帳戶切換回歸。指定帳戶分享的 API、資料表及 UI 不再存在；不需要資料庫遷移或部署。
