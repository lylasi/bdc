# 擴充套件本機安裝與手動測試

適用於目前已打包的 BDC 語境查詞擴充套件 0.1.0。Worker 已在線上，本機無須另開 HTTP 伺服器或重新部署。

## 載入擴充套件

1. 在 Chrome 開啟 `chrome://extensions`；Edge 則開啟 `edge://extensions`。
2. 啟用「開發人員模式」，選「載入未封裝項目」（簡體介面為「加载已解压的扩展程序」）。
3. 選擇下列整個目錄：

```text
/Users/linus/CODE/bdc-extension-ai-proof-20261105/extension
```

macOS 的選擇目錄視窗可按 `Command + Shift + G`，貼上上述路徑。管理頁應顯示「BDC 語境查詞」版本 0.1.0；可在瀏覽器工具列的擴充套件選單將它固定。

若已載入同一目錄，先在擴充套件管理頁按重新載入，再重新開啟其介面。

## 帳戶與查詞

1. 點工具列的「BDC 語境查詞」。可在頂部切換為「繁體中文（香港）」，再按「在新分頁開啟完整驗證面板」。
2. 在「同步服務網址」填入：

```text
https://bdc-sync-api.penzibdc.workers.dev
```

3. 選擇自己既有帳戶的登入方式：使用者名稱與密碼，或通行碼（Token）；填寫後按「連接並同步 AI 配置」。
4. 預期看到「已連接帳戶」、管理供應商就緒，以及目前查詞模型。沿用目前 managed catalog 時，供應商為 HAPI，查詞模型為 grok-4.20-fast；若管理員後來更新配置，以當前介面顯示為準。無須手動編輯 managed catalog。
5. 在「字詞或詞組」填 `charge`，在「所在原句」填 `They charge £10 for admission.`，附近語境可留空，按「語境查詞」。
6. 預期查詢結果解釋 charge 在句中表示「收取費用」或相近含義，並顯示詞性與模型資訊。表述可隨 AI 回答不同。

## 網頁選詞

1. 在一般英文網頁選取一個單詞或短語，保持該文章分頁在前景。
2. 從瀏覽器工具列開啟 BDC 擴充套件彈窗。
3. 按「從目前分頁擷取選中詞」，確認字詞及所在原句帶入，再按「語境查詞」。

瀏覽器設定頁、擴充套件管理頁等受保護頁面不提供一般網頁的擷取能力；這些情況可使用上方手動輸入流程。
