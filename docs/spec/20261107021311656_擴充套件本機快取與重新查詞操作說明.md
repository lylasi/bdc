# 擴充套件 0.6.3：本機快取與重新查詞

查過的成功結果仍保存於本機，單詞及短語預設有效期 30 天。快取按單詞／短語、原句與附近語境、供應商及上游網址、模型與思考程度、語言、帳戶及同步端點、catalog／prompt 版本區分；換語境或設定不會強行套用另一份意思。

## 閱讀時

1. 選詞後開啟詞卡，符合條件的本機快取會先直接顯示，旁邊有「本機快取」標記。詞書及帳戶配置同步在背景進行，不再把這些網絡請求排在快取顯示之前。
2. 詞卡底部保留短的「加入」、詞書圖示及圓箭嘴重查圖示。詞書圖示開啟原有的選書／新增詞書對話框；加入仍保存目前展示的釋義、原句及來源。
3. 圓箭嘴可隨時重查目前單詞。它只略過這一次快取，成功後更新原快取；下一次普通查詞可重用新結果。重查期間圖示暫停操作，成功和失敗後都保留。
4. 重查失敗會直接在詞卡顯示原因，沒有把失敗寫成成功快取。恢復服務後可再次按圖示；既有最後成功結果不會因失敗而被覆蓋。

本機快取沒有跨裝置同步，也不是查詞歷史列表。沒有符合條件的快取時仍需等待正常 AI 查詢；儲存詞條、同步及新 AI 請求仍按原有登入和憑證規則執行。登出、401 或切換帳戶會清除當前顯示及丟棄遲到結果。

## 更新

若瀏覽器直接載入 `/Users/linus/CODE/bdc/extension`，在 Chrome／Edge 擴充功能管理頁按重新載入，確認版本 **0.6.3**，再刷新原閱讀網頁。

亦可下載 [0.6.3 ZIP](../release/assets/20261107032636097/BDC-extension-0.6.3.zip)，以包內 `extension/` 更新原安裝資料夾，再重新載入及刷新網頁。沿用相同安裝位置與瀏覽器設定檔，才能繼續使用該擴充套件原有的本機資料。
