# 選詞旁查詞小窗與快速收藏操作說明

版本：擴充套件 0.4.0。普通網頁選取單詞或短語，再按附近的「查詞」，結果會在選詞旁顯示小窗。

## 更新

```bash
git pull --ff-only origin master
node scripts/package-extension.mjs
```

到 chrome://extensions／edge://extensions 重新載入 extension/，確認版本為 0.4.0；原本已開啟的文章頁面重新整理一次。帳戶和 AI 設定沿用原同步服務，無需另建或另部署服務。首次登入仍從擴充套件工具列或「更多 → 帳戶設定」完成。

## 閱讀與查詞

- 選詞本身不呼叫 AI；明確點「查詞」才開小窗並查詢。
- 小窗約 340px 寬，高度隨結果調整。優先放選區下方，空間不足改上方，左右靠邊時自動避讓；長內容可在小窗內捲動。
- 預設只顯示字詞、音標、詞性、句中釋義及收藏。頁面或容器捲動時跟隨選詞；選詞離開可視範圍便收起。
- 點小窗外面或按 Esc 收起；在小窗內點擊、選書或收藏不會誤關。每頁只保留一個結果窗，再點另一詞的「查詞」才替換。
- 載入失敗可在小窗重新查詢；沒有登入時提供登入提示，可從「更多 → 帳戶設定」連接帳戶。

## 快速收藏

詞書依次沿用「同頁明確選擇 → 本頁詞書 → 明確預設詞書」，可隨時從下拉選單切換。所有候選都必須仍然有效；不以名稱或排序猜測預設。

沒有可用目標時，按「建立本頁詞書並加入」，直接以網頁標題建立頁書並收藏目前展示的釋義。先確認建書回執，再加入當前結果；過程不再次呼叫 AI。若需自訂名稱或設為預設，使用「更多」中的原有詞書操作。

只有收到保存回執才顯示「已加入」。網路失敗或回應遺失會保留待傳，從「更多」處理重試或取消；取消本機待傳不會刪除雲端已保存內容。

## 更多與編輯

「更多」會將同一個查詞窗展開為完整面板，保留結果、目標詞書及來源，提供編輯選詞、帳戶設定、詞書管理、待傳及文章匯入。切換形態不重跑 AI。

完整面板不會因點外面或捲動而關閉。文章預覽或詞書表單有未保存內容時，按關閉／Esc 會先詢問繼續編輯或放棄。返回小窗時也會保護未保存內容；進行中的操作需先完成或停止。

AI 擷取文章、可選逐段分析和同頁詞書自動關聯沿用 0.3.0。保存後可返回小窗繼續閱讀，亦可在 BDC 開啟文章詳解。

瀏覽器內建受保護頁面仍不可注入；使用工具列可手動查詞。重新整理或離開原頁會由瀏覽器卸載浮窗；保存成功以回執及 BDC 同步結果為準。
