# 擴充套件 0.6.0：精簡查詞、文章助手與來源跳轉

## 更新方式

在專案根目錄執行 `node scripts/package-extension.mjs`，然後到 Chrome／Edge 擴充套件管理頁重新載入 `extension/`。已開啟的閱讀網頁也要重新整理，才會載入新版選詞與懸浮球。主站新增的文章／詞書跳轉需使用本次更新的主站檔案。

## 日常查詞

在網頁選取單詞或短語後按「查詞」，小卡保留字詞、音標、詞性、句中釋義、目標詞書及加入操作。

- 鉛筆圖示：按需開啟選詞／原句編輯對話框。取消編輯會恢復原來的詞卡；提交查詞才採用修改。
- AI 圖示：開啟頁內助手，自動引用目前字詞與原句，輸入問題後送出。
- 詞書圖示：直接開啟目前選中的詞書。
- 設定圖示：開啟帳戶、服務、語言、AI 模型及思考程度。選擇一改即儲存；不常駐佔用詞卡高度。
- 更多圖示：保留詳細結果、詞書管理及待傳操作。

## 文章 AI 助手

一般 http(s) 網頁右下角預設顯示懸浮球，沒有選字也能打開。擴充下拉的「在網頁顯示懸浮球」開關會記住選擇，並即時更新已開啟的網頁。BDC 主站沿用自己的助手入口。

打開球會讀取目前文章供提問使用；按下送出前不會呼叫 AI。助手以小浮窗開始，可切換右側欄。支援連續對話、串流、停止、失敗重試及新對話。Enter 送出、Shift+Enter 換行；輸入法組字時不會誤送。對話與草稿保存在本機，按同步服務、帳戶、原文頁面及正文版本區分；切換帳戶會清空當前畫面的舊對話。

模型／思考設定中的「AI 助手」用途可獨立選擇。重試會沿用該次原請求的問題、模型與思考設定。

## 文章提取與獨立閱讀視窗

擴充下拉按「文章詳解」會開啟獨立文章視窗，可以提取、編輯預覽、選擇逐段分析、保存並開啟文章。來源綁定發起操作的網頁，開啟新視窗後不會誤讀其他作用中分頁。

也可在網頁按右鍵，選擇「用 BDC AI 提取並導入文章詳解」（實際文案跟隨介面語言）。此入口直接在獨立視窗提取、分析並匯入；完成後在該視窗進入 BDC 文章詳解。既有同來源文章優先復用，避免重複建立。進度與錯誤留在文章視窗，無需一直打開右上角下拉。

## 文章、詞書與原文來源

文章閱讀工具列的「詞書」入口可直接查看對應詞書；尚未有專屬詞書時，會先確認再建立。詞書的來源橫幅提供返回文章與開啟原文的入口；原文連結只接受安全的 http(s) URL。

既有資料依 articleId、舊版 storageId、明確的詞書關聯及同一頁 sourceUrl 解析，不按相似標題猜測。舊資料若未保存來源或關聯，系統不會虛構原文連結。

深連結：文章使用 `#a/<articleId>`；指定詞書使用 `#v/<bookId>`。ID 需以 `encodeURIComponent` 編碼，舊版 `url:...` ID 也遵循此規則。詞書尚未同步到本機時保留連結，待同步完成後重試定位。

詞書 JSON 匯出會附上可識別的文章 ID 及安全原文來源，字詞仍保留舊版字串格式以兼容舊匯入。重新匯入與覆蓋同名詞書會保留來源及詞書 ID，避免既有深連結失效；明確換成另一來源時會清除過時的文章綁定。
