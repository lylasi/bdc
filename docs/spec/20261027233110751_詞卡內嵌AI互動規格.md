# 詞卡內嵌 AI 互動規格

使用者已確認全部採用推薦方案。

## 互動

- 單詞詳解的 AI 圖示在詞卡底部展開問答區，不自動開啟右下角助手，不自動發送。
- 輸入框保持空白；所選單詞、精確原文位置及原句作為背景隨提問送出。
- 答案區約顯示 6–8 行，超出後在區內捲動；輸入框保持可用。
- 問答展開後點擊頁面空白處保留詞卡；按 × 或 Escape 可關閉，點另一個詞可切換。
- 每個單詞位置與原句獨立保存對話；再次開啟同一位置可繼續，記憶體內保留未送出的草稿。
- 展開圖示把同一個問答區移入大視窗，可返回詞卡；對話、草稿與進行中的串流連續保留。
- 保留共用助手的停止、錯誤重試、Markdown 與閱讀記錄來源；帳戶或文章版本失效時清理可見狀態，防止跨帳戶寫入。
- 新介面文案與無障礙標籤同時支援 zh-CN 及 zh-HK；歷史訊息與使用者輸入不轉換。

## 驗收

驗證精確的第二次同詞引用、獨立對話、重新開啟及草稿、空白點擊、鍵盤與輸入法、串流彈出及返回、停止及重試、雙語、手機寬度與鍵盤可視範圍、帳戶隔離，以及既有助手的回歸測試。
