# 文章學習記錄側欄修復 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修復文章學習記錄的刪除與狀態可靠性，完成緊湊瀏覽、搜尋排序、原文往返和響應式雙語介面，交由 DeepSeek 獨立複核至驗證完成。

**Architecture:** 沿用 reading-store 的永久資料／outbox，不改同步協議。清單視圖選擇抽成 feature 內的純模組；reading-panel 維持單一面板與草稿來源，控制項穩定、卡片按項目 ID 恢復焦點。樣式依可讀寬度選擇桌面並排與小螢幕模態。

**Tech Stack:** ES2022 ES Modules、原生 DOM、IndexedDB、node:test、Playwright、Python 本地伺服器。

**Spec:** [整合評估](../research/20261028014811635_文章學習記錄側欄優化整合評估報告.md)

## Global Constraints

- 使用 ES2022、4 空白縮排、單引號。
- 新增 DOM 參照時，優先擴充 `modules/dom.js`。
- 使用者可見文字必須同時支援大陸簡體中文與香港繁體中文，預設介面為 `zh-CN`。
- 介面切換不得轉換文章、筆記、歷史 AI 內容。
- 保留目前工作區其他文章路由／刷新等未提交改動；不提交、不重設、不覆蓋。
- 不呼叫正式 AI／帳戶；瀏覽器用隔離 context、合成資料及 mock。
- 不新增理解狀態、不複製聊天管理、不新增分享能力；報告 P3 不列本次實作。
