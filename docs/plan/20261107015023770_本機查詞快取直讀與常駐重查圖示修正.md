# 本機查詞快取直讀與常駐重查圖示修正

針對目前工作目錄的 0.6.2 擴充套件修正。原目錄已有多輪已交付但未提交的開發，只改本輪所需程式，保留既有功能與私人配置。

## 已確認的等待路徑

詞卡初始化先等待 captureUI.sync、workspaceUI.sync 及 syncExtensionAccountAI，才執行查詞。共用 lookupSelection 又先做可下載 managed credential 的非同步解析，之後才讀取快取。雖然結果保存在本機，仍會等待與結果無關的網絡操作。原 ext-inline-retry 僅無結果時顯示，成功後會被隱藏。

## 實作

1. 共用 API 增加只讀本機快取入口，沿用既有詞／原句／語境、供應商連線、模型、思考、語言、帳戶、catalog 及 prompt 版本鍵；只讀快取可使用已保存的公開 catalog metadata，不下載 Key，不授權新的 AI 請求。
2. 擴充套件優先讀取相同帳戶的成功快取；詞書與工作區初始化不阻塞顯示。快取未命中才等待完整 AI 設定同步及正常請求驗證。登出／401／切換帳戶與查詞序號保護保持有效。
3. 詞卡顯示簡短的本機快取標記。收藏按鈕改為短文字、取消撐滿整行；footer 常駐重查 SVG 圖示，一次強制略過快取，不改寫之後的預設查詞偏好。兩語 tooltip、aria-label 及窄窗一併驗證。
4. 真 MV3＋本機 Worker／SQLite 重現關窗再開、刷新頁面、跨網站頁面、網絡同步被按住仍能即時讀取、強制重查及模型／語境／帳戶隔離。新失敗不快取，重查成功更新原快取。交 DeepSeek 做範圍明確的獨立驗收。
