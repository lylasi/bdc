# 擴充套件加入詞書實施計劃

接續已驗證的獨立 AI 查詞，完成「選詞 → 查詞 → 選既有詞書 → 明確收藏 → BDC 同步看見 → 查看來源」的下一個可驗收步驟。實作由 Codex 負責，完成後交 DeepSeek 獨立測試及 Codex 審核。

## 本次範圍

- 新增現有 Worker 的 GET /vocabulary/books、GET /captures/capabilities、POST /captures，selfhost 共用相同 handler。
- 詞條沿用 reading_entities／reading_changes／reading_state，不寫入或覆寫舊快照。新增獨立收藏回執表，使用附加 migration；不修改既有文章／閱讀資料的識別方式。
- 收藏使用目前已展示的有效釋義，不重跑 AI。保存單詞、音標、詞性及來源的原句、附近語境、原網址、標題、當次意思與時間。
- 同詞在同一詞書中追加來源；不覆蓋使用者已編輯的釋義。相同 requestId 重送回原回執，改內容回衝突；刪除後重播不復活。不同詞書各自保存。
- 捕獲來源欄位進入共用白名單、永久儲存、備份／還原及主站來源顯示。來源達 100 筆時明確回報，不能靜默裁切。
- 擴充套件提供目標詞書、收藏按鈕、本機待傳及重試狀態。immutable outbox 按 endpoint／user 分區，不包含帳戶 token 或 AI Key；每筆各自保存，避免多彈窗覆寫整個佇列。
- 以目前受信任頁面的登入狀態傳送；開啟面板、同步及連線恢復時重試。關閉彈窗後保留本機待傳，重新開啟後繼續；不增加背景憑證副本或額外擴充套件權限。
- 網頁來源隨選詞擷取；手動變更查詢或重新擷取後，舊解釋不能被收藏。從獨立面板手動查詞時允許沒有來源網址，不能沿用其他分頁的舊網址。
- 主站手動同步及返回前景可發現 reading cursor 的更新，不依賴 snapshot version 改變。

## 階段邊界

此步先交付詞書收藏與來源。獨立待讀文章列表、正文導入、句子解析和進階面板接在後續步驟；較早 A 方案中這些能力的完整範圍仍保留。新建詞書沿用主站操作，擴充套件先選既有詞書。

## 驗證

使用真正 SQLite＋D1 adapter 測試後端成功、來源去重、不同網址、保留編輯、目標刪除、跨帳戶、冪等重送／回應遺失、並發及交易回滾。用真正 MV3 與隔離本機服務測試選詞／收藏、重開後待傳重試、帳戶與端點切換、兩語 UI，以及主站同步與來源備份往返。

執行受影響的 reading／AI 回歸及字典審計。DeepSeek 在實作可執行後測試，禁止把 mock 當成正式聯調。本階段先完成可審閱的實作與隔離測試，再依會話授權安排正式 migration／發布，不把尚未發布的接口說成已在線上可用。
