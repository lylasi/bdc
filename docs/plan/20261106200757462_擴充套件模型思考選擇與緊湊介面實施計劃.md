# 擴充套件模型、思考選擇與緊湊介面

使用者要求：讀取帳戶 API 後能切換模型與思考程度，並指定 DSH 美化選詞旁小窗、完整面板和帳戶設定。

## 實作與分工

- Codex：沿用 ai-models 的允許清單、任務解析及思考協議，增加可信擴充套件控制器。預設顯示目前查詞任務，也可設定文章擷取、段落翻譯及詳解。模型、思考程度即時保存，按 endpoint / user 隔離。選擇只影響後續請求，不自動收費重查，不改寫已展示釋義或收藏內容。
- 擴充套件偏好與雲端帳戶設定分開保存：帳戶同步後重套本擴充套件的明確選擇，提供恢復帳戶設定，不向網頁傳模型設定、Token 或 Key。登出及帳戶切換清理沿用帳戶邊界。
- DSH（DeepSeek Harness，Codeg task cb3a02f8-5ffb-4f1a-a1b4-74d1fd11341a）：只修改 lookup.html / lookup.css 及 page-lookup 的純視覺樣式，壓縮卡片留白，保留現有 IDs、i18n、安全訊息及幾何行為。
- Codex 審核整合後交 DeepSeek 獨立驗證真 MV3 模型／思考請求、重開及帳戶隔離、兩語窄窗與既有收藏／文章功能。
