## Review Focus

1. Same word in different sentences: keep one entry per target book, append contextual sources/meanings, preserve user-edited primary meaning.
2. Server committed but response lost: retry the same immutable request ID, return original result, no duplicate entry or saved URL, no silent restoration after a later deletion.
3. Account/tab/selection switches during async work: old responses and pending operations stay with their original identity; no credential or content crossover.
4. Missing URL, restricted page or phrase: save actual text/context, no guessed previous URL, handle missing context and phrase classification gracefully.
5. New sources/saved-page data survive normalization, backup/restore and sync; >100 sources cannot silently drop the user's new capture; new saved-page type cannot poison old reading sync.
