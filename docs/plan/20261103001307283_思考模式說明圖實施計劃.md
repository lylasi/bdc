# 思考模式說明圖 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在模型設定加入可點擊的說明圖示，展開五種思考模式的作用、適用場景及渠道限制。

**Architecture:** 在既有「按功能指定模型」與文章／查詞快速模型視窗加入原生details／summary說明入口，使用既有ic-info SVG與可讀文字、強度圖示組成對照圖。共用modules/ai-thinking-help.js，沿用THINKING_LEVELS、既有標籤與data-keep-open，保持模型／思考設定及儲存邏輯不變。

**Tech Stack:** 原生ES Modules、HTML details、CSS、zh-CN／zh-HK i18n、Playwright。

**Spec:** 使用者本輪要求：在已有思考強度設定旁加入圖片，點擊可了解各種強度的作用。介面有auto、none、low、medium、high共五檔；最低強度是部分渠道的降級行為，不另新增檔位。

## Global Constraints

- 所有新增可見文字使用t()；兩份locale同時完成。
- 說明以使用者用途為主，不展示API參數或固定token預算。
- 清楚區分服務端預設、請求關閉與低檔；高檔不保證更正確，隱藏思考內容不等於關閉。
- 不更改實際模型選擇、思考預設、帳戶或同步資料。
- 文件落在docs/plan及docs/report，以yyyyMMddHHmmssfff命名；保留其他工作。

## Review Focus

- 手機窄畫面：圖示可觸控，說明完整換行，不產生橫向捲動。
- 鍵盤與閱讀工具：原生summary支援Enter／Space，圖中有可讀名稱與說明。
- 設定重繪：改思考模式後，說明圖維持展開。
- 雙語：圖示提示、標題、每檔用途及注意事項均切換正確。
- 說明語義：展示項與實際五檔一致，不承諾所有模型真的能關閉。
