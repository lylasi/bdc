## Gemini 開發

1. 閱讀實際 AI 任務解析、thinking、語境提示、供應商適配、catalog、憑證同步與登入介面，抽最小可注入環境邊界，不複製另一套協議或完整提示詞。
2. 實作獨立 extension origin 的登入/連接與設定載入；管理員供應商及已同步個人供應商沿用現行格式。僅網站本機的 Key 不會自動取得，缺失時清楚提示，若提供匯入必須明確、按 endpoint/user 隔離。
3. 提供可直接載入的 MV3 原型及 `lookupSelection({ text, sentence, context, locale, signal })` 共用入口。取詞可用使用者操作後的 activeTab/scripting，受限制頁面可手動輸入；不依賴隱藏 BDC 分頁。
4. 正確沿用查詞/單詞分析的模型、供應商及思考設定。快取區分 endpoint、帳戶、供應商、模型、詞句、附近語境、語言及提示版本；帳戶/輸入切換時舊回應不得污染新狀態。
5. 共享 Key 僅留記憶體；內容腳本不持有登入 token 或 AI Key；所需跨 origin 權限有實際可驗證路徑。不要擴大既有 CORS 到任意來源。
6. 所有 UI 及錯誤文字同時支援 zh-CN/zh-HK，動態文案使用 t()，保留原文。
7. 寫有意義的測試及可重現安裝/模擬驗證說明，實際載入打包目錄，在沒有 BDC 分頁下跑 mock 帳戶與供應商連線。標明 mock 與真實帳戶/生產部署的界線。
