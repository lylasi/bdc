# TTS 個人帳戶保存與擴充登入帶入

目標：明確說明擴充設定入口，將現有本機 TTS 設定加入帳戶保存，登入主站及擴充可恢復服務、聲音及所需 Key。

實作：TTS 公開設定獨立快照群組；API Key 復用現有 AES-GCM 個人憑據儲存的專用槽位，絕不放入普通快照。保持裝置聲音及擴充播放模式為裝置偏好。依端點及帳戶隔離本機資料；舊資料只遷移一次，雲端既有設定優先，空白新擴充不覆蓋主站。服務地址與 Key 綁定，切換地址不能發送舊地址的 Key。

驗證：主站保存／重新登入／新擴充自動帶入，真 Worker+SQLite 檢查密文，快照無明文 Key，並行版本衝突、離線重試、舊回應、換帳戶／端點及雙語錯誤。完成後打包、推送並更新 149，保留既有私有設定。
