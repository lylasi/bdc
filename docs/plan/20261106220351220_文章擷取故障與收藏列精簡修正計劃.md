# 文章擷取故障與收藏列精簡

使用者回報：AI 擷取文章時顯示無法連接同步服務，DevTools 的 books?sourceUrl 請求失敗；收藏區的詞書、來源、提示與按鈕過度佔位。

## 實作

- 排查已保存文章預查、同步連線錯誤、取消及後續儲存流程。預覽所需的網頁正文與 AI 已在擴充套件內可用時，暫時性的去重預查連線錯誤不阻塞預覽；儲存仍執行去重、回執、關聯與待傳流程，401/帳戶切換/取消不能被容錯吞掉。
- 詞書、加入、更多併成一行；次要新建、預設、重新整理和來源入口收合，保留錯誤與待傳狀態的可見性。沒有可用詞書仍能直接建立本頁詞書並加入。
- 文章操作縮為緊湊一行，預覽與實際錯誤按需展開；所有新增文案完成 zh-CN/zh-HK。
- Codex 開發及審核；DeepSeek 定向診斷後端／網路，再做針對性複測。先測本地錯誤注入、真 MV3/SQLite、窄窗及雙語，完成後依既有授權更新 remote、原 checkout、149；有後端改動才評估原 Worker 部署。

原 checkout 的未追蹤文件和私有 ai-config.js 保留。隔離樹只使用公開範例配置。
