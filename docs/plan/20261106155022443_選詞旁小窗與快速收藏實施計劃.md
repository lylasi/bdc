# 選詞旁小窗與快速收藏實施計劃

依使用者已確認的 Q1–Q7 設計，實作擴充套件 0.4.0。Codex 開發及最終審核，DeepSeek 獨立測試。

## 功能

- 選詞後明確點查詞，約 340px 的小窗貼近選區，內容自適應高度，視窗邊緣翻轉及夾限；支援頁面及容器捲動跟隨、移出可視範圍收起、縮放重算。
- 小窗只顯示詞、音標、詞性、當句意思及收藏操作；更多展開同一 iframe 的完整面板，保留查詞、詞書及文章狀態，完成後可返回。
- 點外面或 Esc 收起一般小窗；面板編輯及操作進行中不自動收起，明確關閉時保護未保存內容。
- 有效的同頁選擇、本頁詞書及明確預設依次沿用；無選擇時可一鍵建立本頁詞書並加入，沿用 immutable outbox、伺服器回執及帳戶隔離。
- 大陸簡體與香港繁體同時完成；已存在的工具列及 options 入口保留。

## 技術邊界

保留可信擴充套件 iframe、共用 AI 及收藏 API，不把憑證帶入網頁。尺寸、模式、保護狀態和關閉請求以驗證 sender／documentId／ticket 的擴充套件內部訊息傳遞，不向普通網頁廣播票據。新選詞只在明確點擊後替換；保存途中和帳戶切換不把舊詞送到新帳戶或新詞。

## 驗證及更新

DeepSeek 以真 MV3、真 Worker／SQLite及隔離 AI transport 測幾何、視窗邊緣、多行短語、捲動、外部點擊、Esc、編輯保護、模式切換、建書再收藏、訊息偽造及兩語。原收藏、文章工作區、AI、設定及 i18n 必要回歸照規則執行。確認生成包無私有配置、乾淨源碼可安裝，再依既有授權推送 master 及更新 149。後端 API／schema 無本次變更時沿用原 Worker，無須新部署。
