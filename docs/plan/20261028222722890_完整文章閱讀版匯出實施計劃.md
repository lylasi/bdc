# 完整文章閱讀版匯出 Implementation Plan

狀態：2026-10-29 已完成本機實作及驗證；詳見[驗收報告](../report/20261029094638558_完整文章閱讀版匯出驗收.md)。保留在原隔離工作副本，未提交或部署。

> **For agentic workers:** 使用既有 executing-plans 指引分項實作與驗證；已在隔離工作副本工作。2026-10-29 使用者另已授權「更新，並pull149」，後續按既有 Git pull 流程發佈。

**Goal:** 將閱讀筆記提升為含原文標記、學習記錄、筆記、錄音及 AI 對話的獨立 HTML 閱讀版。

**Architecture:** 由既有 reading-store 交易取得單篇快照，再由純呈現模組產生無外部依賴的 HTML。reading-export 負責上下文與檔案讀取／下載；reading-panel 共用兩個入口並保存所有草稿。

**Tech Stack:** 原生 ES2022 Modules、IndexedDB／localStorage、HTML／CSS、FileReader、Playwright、node:test；不新增套件。

**Spec:** [完整文章閱讀版匯出規格](../spec/20261028222722890_完整文章閱讀版匯出規格.md)

## Global Constraints

- 使用 ES2022、4 空白縮排、單引號。
- 新使用者可見文字同時完成 zh-CN／zh-HK，原始內容不翻譯。
- 只使用單篇、單帳戶快照；每次 await 後確認上下文。
- HTML 不攜帶憑證、不依賴開發伺服器、不自動載入遠端圖片。
- 文件保存在 docs 分類目錄，檔名包含 yyyyMMddHHmmssfff。

## Task 1：資料快照與隔離

**Files:** modules/reading-store.js、對應匯出／fallback 測試。
**Interface:** exportArticleReading(articleId, ctx) 保持原簽名及結果欄位，補齊單篇限制及 lastOpenedAt。

- [x] 以兩篇相同帳戶資料驗證 fallback 不混入另一篇的記錄、文件、會話或詞彙。
- [x] 使用嚴格讀取處理 fallback，確保 preflight 和帳戶切換失敗可見。
- [x] IndexedDB 與 fallback 傳回一致的本機閱讀時間與文章相關內容。

## Task 2：HTML 閱讀版及錄音

**Interfaces:** buildReadingEditionHtml({ articleId, includeChat = true, audioFiles = [], context, isCurrent }) 回傳 { ok, html, meta } 或 { ok:false,error }；exportReadingEditionFile(options) 驗證後下載 text/html。

- [x] 從單篇快照篩選存活記錄及關聯，按時間／ID 排序訊息。
- [x] 驗證版本、界限、quote、positionUncertain；以區段邊界處理重疊標記，所有關聯保留可導航連結。
- [x] 呈現原文、記錄、筆記、AI 文件及對話；保留舊版／位置不明記錄及來源缺失提示。
