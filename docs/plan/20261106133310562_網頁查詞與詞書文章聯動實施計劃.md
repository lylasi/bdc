# 網頁查詞與詞書文章聯動實施計劃

依使用者本輪要求，實作原網頁選詞查詢、擴充套件內建詞書／預設詞書、AI 擷取文章標題正文並導入文章詳解、同頁詞書與文章自動關聯。沿用現有帳戶、AI 共用入口、文章 API、reading 資料與同步，版本目標 0.3.0。

## 操作流程

1. 在普通網頁選詞，出現查詞入口；點擊後在原網頁浮窗呈現語境解釋與收藏。帳戶設定仍在擴充套件可信頁面。
2. 收藏可選現有詞書，也可直接建立本頁詞書、自訂詞書或預設生詞本。明確設定預設後，其他頁面可沿用；本頁臨時選擇按帳戶／服務隔離。
3. 文章入口從當前頁面取得可讀正文，沿用 AI 清理任務擷取標題與正文，提供可修改預覽後導入 BDC 文章詳解，保留章節與原語言。
4. 相同網頁的詞書和文章使用來源網址關聯，支援先建詞書或先導入文章；既有文章與詞書優先沿用，刪除資料不因重試復活。

## 實作邊界

- 頁面腳本只處理選取與浮窗，不接觸 token／Key；可信擴充套件 iframe 執行共用 AI 與收藏程式。由可信使用者操作取得一次性分頁憑據，驗證訊息來源及操作種類。
- 不在背景 service worker 重寫 AI 接入，亦不在普通網頁執行攜帶 Key 的 fetch。
- 新增帳戶範圍的預設詞書偏好及冪等建書 API；沿用既有 reading_entities 和回執表。新增偏好表使用附加 migration，同時支援 selfhost。
- 文章沿用現有配額、版本及冪等 API；匯入後能在文章詳解開啟並分析。AI 擷取不偷偷改成翻譯或擴寫；截斷和空結果須明確提示。
- 以有效文章身份建立關聯，詞條保留原網頁引用；不把原 DOM offset 當成清理後正文的位置。
- 新增文字完整支援 zh-CN／zh-HK，功能程式維持一套；所有 UI 非同步狀態及錯誤均有可讀提示。

## 驗證與發布

Codex 開發及最終審核，依使用者既有分工交 DeepSeek 獨立測試。驗證真 MV3 網頁浮窗、嚴格 CSP、帳戶隔離、訊息邊界、建書／預設／離線重試、文章擷取預覽／保存／重送／自動關聯雙向時序、主站顯示、兩語及 400px 排版；完成既有 AI、收藏及同步必要回歸。測試通過後按既有授權更新原 Worker／149／remote，備份後套用附加 migration，使用隔離正式 fixture 並清理。
