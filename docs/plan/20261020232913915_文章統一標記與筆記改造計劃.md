# 文章詳解：統一標記與筆記改造計劃

狀態：使用者已批准並要求實施。指定執行助手：代碼執行（assistant_id: 1）。

## 最終操作規則

取消「未標記／待弄懂／已理解」三檔理解狀態，正文只用一種下劃線表示主動標記。

| 操作 | 結果 |
| --- | --- |
| 查詞、查短語、查句子 | 保存查閱記錄和解釋，方便下次快速讀取，不自動標記 |
| 加入單詞本 | 自動標記當前選中的詞或短語，包括詞書已有該詞的情況 |
| 點擊標記 | 給當前詞、短語或句子添加下劃線 |
| 點擊取消標記 | 移除該條目的下劃線，保留詞書、釋義、來源關聯及筆記 |
| 寫筆記 | 自動保存到對應文章、對應位置的記錄 |
| 從單詞本移除 | 保留文章標記及筆記，分別管理 |

筆記獨立保存，寫筆記不改變標記狀態。取消標記後的筆記仍可在「筆記」篩選找到，後續編輯不重新標記。

## 界面與流動裝置操作

- 單詞彈窗保留點擊查詞，加入「標記／取消標記」「寫筆記」。解釋載入中或失敗時也能操作；標記與寫筆記本身不請求 AI。
- 短語選擇保留手機「點首詞→點末詞」，將「仍不懂」替換成標記切換，旁邊保留加入詞書、寫筆記。
- 原生選字工具列增加標記與寫筆記入口，使用已捕捉的選區。
- 單詞及原生選區寫筆記入口打開閱讀記錄面板，定位並聚焦對應筆記框；短語選擇器沿用既有編輯框。自動保存，關閉、切換及匯出前提交草稿，失敗時保留輸入。
- 閱讀記錄「待弄懂」篩選改為「標記」，卡片改為單一切換按鈕。保留詞書徽標、查閱記錄與筆記。「刪除記錄」與「取消標記」明確分開。
- 正文統一輕量下劃線，保留顯示標記開關。同詞不同位置分別管理；重疊標記取消一個後仍顯示其他有效標記。
- 文案同時完成 zh-CN、zh-HK，動態文字用 t()，按鈕提供選中狀態與無障礙名稱。

## 資料、遷移與雲端同步

### 最小模型調整

在現有 learningItem 增加 marked: boolean，沿用 note、articleId、contentVersion、anchor 與詞書關聯，不新增標記表。提供 setMarked(itemId, marked, actionContext)。舊 understanding 只用於舊資料兼容，不再參與新版 UI、標記樣式或 AI 理解程度判斷。

### 保存與精確定位

- 加入詞書時，詞條、來源關聯、marked: true 與 outbox 同一個本地交易保存，失敗整批回滾。
- 修改既有條目時在交易內讀取最新記錄，只修改明確指定欄位，不以過期記憶體整筆覆蓋另一分頁筆記。
- 補齊查詞彈窗加入詞書時缺失的精確位置。所有入口固定文章、版本、引用位置及帳戶上下文，異步完成不可寫錯文章或帳戶。
- 明確 marked:false 優先。刷新、重查、AI 回應、詞書載入和同步均不得依既有詞書關聯重新標記；再次主動加入詞書才重新標記。

### 舊資料兼容

僅對缺少 marked 的舊記錄遷移：舊 needs_review、understood 或有效詞書關聯轉為 true；僅查閱、僅筆記轉為 false；已有布林值原樣保留。按文章載入或舊資料匯入時遷移，可重試、冪等，維持啟動懶載入。完整備份、還原及驗證同時支援新欄位。缺失欄位不能視為明確取消，不得由遠端缺欄位覆寫本地明確狀態。

### 同步契約

- shared/reading-protocol.mjs 增加 marked 校驗、patch 白名單、三方合併與刪改衝突支援。
- Cloudflare／selfhost 共用路由 GET /reading/capabilities 增加 learningItemMarked: true。
- 新前端確認此能力後才同步閱讀資料。舊後端不支援時保留本地資料及 outbox，顯示服務端需要更新，不能默默清掉待同步修改。
- 發佈順序：後端先、前端後。本輪本地實施驗證，不自動部署正式雲端、不提交或推送。
